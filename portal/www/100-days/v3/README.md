## 源码、运行与接口

源码是 `E:\Projects\New project\day100-film\versions\v3\site\`。独立生产目录是 `E:\Projects\portal\www\100-days\v3\`。不会覆盖 `/100-days/index.html` 或旧版资源。

| 请求 | 实现 |
|---|---|
| `GET /100-days/v3/` | V3 `index.html` |
| `GET /100-days/v3/film.css?v=<内容哈希>` | 影片样式、13 段独立构图、手机布局和静态阅读模式 |
| `GET /100-days/v3/film.js?v=<内容哈希>` | 一个 rAF 时钟、169 秒播放、暂停/继续、前后段、进度、跳结尾和重播 |
| `GET /100-days/v3/media/<name>.jpg?v=<内容哈希>` | 真实来源的公开裁切图片 |
| `GET /100-days/v3/version.json` | 实际部署版本、资源 SHA-256、时长和保留 V2 的文件哈希 |
| `GET /100-days/v3/README.md` | 本说明 |

没有 DAY100 后端 API、数据库、账号或 SSO 接口。观看 V3 不提交数据，不创建账号，不写入 localStorage，不加载主站登录脚本。片尾的入口在点击后正常导航到现有网站。

总时长由各段 `data-duration` 相加，场景和字幕由同一个浏览器时钟更新；Pause 冻结时间和图片运动。Skip 直接到 169 秒/100%，Replay 回到第一段；前后段按钮按章节边界移动。离开可见页面时暂停，回来后手动继续。键盘空格暂停/播放、左右键换段。来源和浏览入口使用原生 dialog，打开时暂停，关闭后按原状态继续。

`prefers-reduced-motion: reduce` 默认暂停，取消推拉和快切，改用静态画面与可读文字。用户可逐段阅读或明确点击播放；重播仍保持暂停。运行时开启减少动态效果也会暂停。

声音默认关闭，用户点击音符/声音按钮后才建立 AudioContext。配乐是本片原创的轻量五声音型，没有引用主站歌曲；错误、旧方案的尴尬停顿和回望留出静音。可关声音观看。

## 发布

在项目根目录运行现有 Node：

```powershell
node 'New project/day100-film/versions/v3/publish.mjs'
```

发布脚本只复制 V3 的 HTML/CSS/JS、公开裁切图片和本说明到独立目录。入口最后以原子替换写入，所有本地资源 URL 使用内容哈希查询参数，沿用项目既有静态资源版本化方式；`version.json` 和 HTML 的 `data-build` 标识确切版本。脚本比较 V2 四个文件的 SHA-256，保证未被覆盖。

现有统一门户直接提供静态文件，因此不需要重建 Homepage、Gallery 或其他游戏模块，也不需要重启门户。没有更改隧道、域名路由、账户服务或数据库。

当前检查发现 `zszm.iridescently.xyz` 的已有隧道入口使用另一个服务，模块 JS 请求返回 HTML。V3 片尾使用已验证可正常加载的 `https://iridescently.xyz/app/modules/cards/` 统一门户路径。没有修改旧域名服务；这项既有问题不等于 V3 发布失败。灵体页面的截图未达到可用状态，未拿加载页冒充成功画面。
