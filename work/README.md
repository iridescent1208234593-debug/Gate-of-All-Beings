# `work/` 临时工作区

`E:\Projects\work` 只用于短期任务、临时验证和候选产物，不是正式项目目录，也不是长期归档区。

## 归置规则

- 需要持续开发的 Git 分支工作树：使用 `E:\Projects-worktrees`，通过 `git worktree` 创建和管理；不要手工移动已登记 worktree。
- 独立原型、外部项目或需要长期保留的非仓库项目：放到 `E:\External Projects`，并补充项目说明。
- 发布快照、回滚包、审计证据与恢复索引：按项目保留策略归入 `E:\Projects\ops\backups`；不要提交备份数据或运行时凭据。
- 一次性日志、探测结果、临时脚本在任务完成且确认无恢复/审计用途后直接删除；不要把它们变成永久兼容层。

## 清理

任务结束后检查该任务目录的 README/交接说明、Git 引用和活跃进程依赖。确认已完成、已归档或无引用后删除临时内容。不得把未完成的候选、事故证据或仍需回滚的包当成过期资料。
