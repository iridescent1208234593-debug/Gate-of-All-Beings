# 网站管家 · 使用说明

双击同目录的「打开网站管家.vbs」即可打开窗口，无需输入命令。
本版管家把本机全部站点收进同一张清单，支持**一键恢复全部**，界面改为西木会馆设计系统风格。

---

## 一、窗口怎么用

| 位置 | 操作 | 说明 |
|---|---|---|
| 顶部按钮 | **一键恢复全部** | 按清单顺序逐个启动**未运行**的站点，最后拉起公网隧道；已在运行的站点不会重复启动 |
| 顶部按钮 | 刷新状态 | 检测全部站点的本机响应，并单独检测公网主域名 |
| 顶部按钮 | 打开主站 | 浏览器打开 https://iridescently.xyz/ |
| 顶部按钮 | 打开日志目录 | 打开本目录下的 logs 文件夹 |
| 右上勾选 | 窗口开启时自动照看 | 每 30 秒检查一次；仅启动端口空闲的站点，不结束任何进程 |
| 表格每行 | **打开站点** | 有独立域名时打开 https://域名/；无域名（如 OAuth 代理）打开本机地址 |
| 表格每行 | **打开项目目录** | 打开该站点的源码目录；未部署的站点按钮置灰 |
| 表格每行 | **查看日志** | 打开该站点自己的日志文件（logs/<站点>.log）；首次尚无日志时打开日志目录 |
| 底部「运行记录」 | — | 记录每次启动、跳过、异常的原因与时间 |

状态徽标含义：

- 松绿「正常 · HTTP 200」：端口在监听且页面可访问；
- 赭红「未监听 · 未启动」：端口空闲，可被一键启动；
- 赭红「端口占用 · HTTP xxx（未强制结束进程）」：端口被别的程序占用但页面不健康——**管家只报告，不会杀进程**，请点「查看日志」排查；
- 描金「未部署」：本机暂无对应项目；
- 描金「未配置启动方式」：cloudflared 配置里存在该域名，但不在站点清单中。

### 新增或修改站点

打开 `website-manager.py`，编辑顶部 `SITES` 列表即可，字段含义：

```python
dict(key='juling',              # 日志文件名，唯一
     name='众生之门 · 聚灵',   # 表格显示名
     cwd=r'server\app\src\juling',   # 项目目录
     domains=['juling.iridescently.xyz'],   # 对外域名，可多个；没有就留空列表
     port=5177,                 # 本机端口
     runner='node',             # python / node / npx / powershell
     args=['server.js'],        # 启动参数
     env={'PORT': '5177'},      # 追加环境变量，可选
     wait=25)                   # 启动后最长等待秒数
```

## 三、安全策略（与原脚本一致）

1. **只启动，不结束任何进程。** 端口被占用时管家只报告状态，不强制结束占用程序。
2. **跳过式启动。** 已经正常运行的站点不会被重复启动，避免端口冲突。
3. **只读检测。** 「刷新状态」只做端口连通性与 HTTP 状态探测，不改动任何文件与配置。
4. **启动前先验证。** 项目目录不存在或找不到入口脚本时，直接报告并跳过，不会盲目启动。
5. **可回退。** 改造前的脚本已备份为 `backup\website-manager_20260925.py`。

## 四、界面设计（西木会馆 · Design System）

界面 token 与 `portal\huiguan\design-system\design-system.css` 的 `--qc-*` 一一对应，
代码中只在 `Q:` 字典里出现一次色值，其余全部引用 token；半透明派生色（徽标底色）由主色按权重计算得出，不硬编码 rgba。

| Token | 值 | 在管家中的用途 |
|---|---|---|
| --qc-bg | #f5f0e8 | 窗口底色（乳白宣纸） |
| --qc-panel | #fbf8f2 | 站点卡片、运行记录面板底 |
| --qc-border | #d4cfbe | 卡片描边、分隔线 |
| --qc-text | #3a4a3e | 正文墨绿 |
| --qc-dim | #7a8a7e | 次级文字（本机地址、表头、脚注） |
| --qc-accent | #5a9e8f | 主按钮、正常状态徽标 |
| --qc-gold | #d4a840 | 强调文字、未部署/未配置徽标 |
| --qc-danger | #b3543f | 异常状态徽标 |

字体：标题优先 LXGW WenKai（手写感），正文优先 Noto Serif S:，均按「Noto Serif S: → Source Han Serif S: → 微软雅黑」顺序自动回退，实际生效字体在自检输出中打印。

## 五、日志与自检

- 每个站点的输出写入 `logs\<站点 key>.log`（键名：main / huiguan / oc / zszm / zszm-oauth / game / juling / lingjing / psyche / tunnel），追加写入，不覆盖历史。
- 自检命令（不会启动任何站点，只构建界面并扫描状态）：

## 七、常见问题

- **某站显示「未监听 · 未启动」**：点「一键恢复全部」；Vite 站点首次启动需数十秒，等待状态刷新即可。
- **端口占用但页面不健康**：管家不会结束该进程。请点该行「查看日志」排查，确认是旧进程后再自行处理。
- **公网域名打不开但本机正常**：检查「公网连接 · :loudflare 隧道」行是否「进程运行中」，以及顶部概览里的「公网主站」HTTP 状态。
- **关闭窗口会影响网站吗**：不会。关闭窗口只是关掉管理界面，已启动的站点继续运行；勾选的自动照看也会停止。
- **重启电脑后**：本机托管的网站需要重新启动，打开管家点「一键恢复全部」即可。长期全天在线建议迁移到持续运行的服务器。
- **不要只移动 www 文件夹**：它引用 huiguan 中的模块；改动目录后请同步更新清单中的 cwd。
- **无第三方依赖**：只用 Python 标准库 tkinter，无需额外安装任何包；启动文件（打开网站管家.vbs）需与 website-manager.py 放在同一目录。
