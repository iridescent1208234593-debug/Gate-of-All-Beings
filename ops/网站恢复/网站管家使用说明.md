# 网站管家使用说明

更新于 2026-10-19。双击同目录「打开网站管家.vbs」打开。

双服选服、代码发布和独立资产更新现已拆到[服务器管家](../服务器管家/README.md)。此窗口保留本机开发服务检查，并提供「打开服务器管家」入口。

## 正式站与本机的关系

香港服务器 `154.222.26.70` 独立运行正式站、接口、账户、存档和媒体资源。本机用于开发、构建和预览；关机、休眠、断网不会中断正式站。本机和香港不会同时写同一套正式数据。

正式域名：`iridescently.xyz`、`www`、`huiguan`、`oc`、`spirit`、`zszm`、`game`、`juling`、`lingjing`（后八项均为 `.iridescently.xyz`）。原有旧域名重定向继续保留。

## 操作

| 按钮 / 状态 | 含义 |
| --- | --- |
| 香港正式站状态 | 当前版本、五项后台服务、可回滚版本 |
| 打开服务器管家 | 管理本机新版公网入口、香港代码发布 / 回滚及独立资产增量更新 |
| 刷新状态 | 检查香港服务、公网主站和本机预览 |
| 启动本机预览 | 启动本机网站服务，供开发预览；不会切换公网域名或重新启动旧隧道 |
| 打开主站 | 打开正式站 |
| 本机预览未启动 | 正常的闲置状态，不影响香港正式站 |

发布是手动触发的。保存源码不会自动更新香港。先按项目原有流程完成相关构建、验证与本地发布，再在服务器管家点击「发布香港代码」。本机新版公网入口使用独立网关，所有玩家数据仍由香港提供。

发布器读取 `.releases/production/site` 的正式 Python/页面快照、现有 `server/app/modules` 构建产物、首页发布产物，以及当前预览 API 所需源码；不会代替构建器生成这些文件。

## 数据与回滚

账户数据库、玩家存档、上传图片、配置数据和密钥持续保存在香港的数据目录，发布与回滚只更新程序。电脑上的旧数据是本机预览副本，不会自动覆盖香港。正式站运行后的新数据也不会自动反向复制到电脑。

新版本切换后，若后台健康检查失败，会自动恢复原程序版本。程序回滚不撤销数据库结构变更，因此以后涉及数据库结构变更的版本需要单独设计迁移兼容性。

## 重启与凭据

香港服务由 systemd 开机自动启动。本机旧生产监督任务与 SSH 转发任务已停用，旧隧道启动器和看门狗在香港正式站模式下直接退出。

两个旧的管理员级 marvis 任务当前账户无权禁用；主隧道的 VBS 启动器已加退出条件，另一个仍指向 D 盘旧 preview。它们不再承载这九个正式域名。

发布使用本机专用 SSH 密钥，只能执行状态、上传候选代码、切换与回滚命令。无需在窗口输入或保存 root 密码。不要移动或分享 `.releases/hk-full-migration/deploy_ed25519`。

本机预览的 Portal / OAuth 仍使用 `.releases/runtime` 下的稳定工作目录，避免运行目录锁住本地发布快照。

## 故障定位

- 香港状态检查失败：检查本机到香港 SSH 的网络、专用密钥与 `known_hosts`；这不一定表示公网网站不可用。
- 公网主站显示 502：查看香港 nginx 和后台服务；正式站已经不依赖本机 Cloudflare 隧道。
- 本机旧隧道证书错误：正式站模式不再执行这项检查；关闭旧管家窗口，再双击启动更新后的管家。
- 运行记录与本机预览日志位于本目录的 `logs`。

命令行管理入口：`python ops/hk-release.py status|prepare|publish|rollback`。`prepare` 只打包，不上传或上线。依赖 Python 标准库和 Windows OpenSSH。
