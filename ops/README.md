# 本机运维工具与状态

`ops/` 包含项目维护、构建、发布、管理界面及本机运维工具。除已跟踪的正式源码外，本机新增工具、临时操作说明和备份索引默认留在本机，不随功能提交自动纳入版本控制。

`ops/hk-bandwidth/` 是 `server-control.py` 和维护脚本使用的本机依赖，不能放回临时 `work/`。`ops/stage15_backup.py` 是历史恢复工具；它可能复制 Cloudflare tunnel 配置等敏感文件到 `ops/backups/`，不要在未确认目标目录权限和备份必要性时运行。

提交前按具体任务点名路径，检查工具是否会修改 DNS、服务、数据或发布状态。备份与恢复材料位于 `ops/backups/`，按该目录 README 管理，不提交备份数据。
