# 界面组件源文件 · 画师版

把 `packages/shared-ui` 里的游戏界面组件库（lxh-ui）导成了图，画师可以直接在 Photoshop / Krita / Clip Studio / Affinity / GIMP 里打开修改。**这里的图都是自动从真实代码渲染出来的**，所以和线上看到的一致；重新跑一遍导出脚本就能更新。

> 这个目录不公开、不进站点发布包（`packages/shared-ui/lxh/` 才会发布）。

## 从哪里开始看

| 想做什么 | 打开哪里 |
| --- | --- |
| 一眼看全所有组件和状态 | `lxh-ui/总览/*.png`（每组一张，状态并排，带中文说明） |
| 改某类组件的样子 | `lxh-ui/psd/<编号>-<名称>.psd`（分层，每个状态一个图层组） |
| 要切好的透明图直接用 | `lxh-ui/png/<编号>-<名称>/<组件>_<状态>.png`（已裁边） |
| 改图标 | `lxh-ui/icons/svg/*.svg`（矢量，Illustrator / Figma / Inkscape 都能开）；`图标.psd`、`图标总览.png` 是看图用的位图 |
| 改配色 | `lxh-ui/tokens/色板.psd`（每个颜色一个图层）；`色板.png` 是总览；`tokens.json` 是机器读的原始值 |

所有位图都是 **@2x**（界面里的 1px = 图里 2px）。缩小一半就是实际尺寸。

## PSD 里的结构

- 每个状态是一个图层组，组名 = 中文说明 + `[组件/状态]`。
- 组里从下到上：**底色**（这个组件实际所在的底，可关）→ **整体参考**（合成好的整图，默认隐藏，拿来对照）→ **各个部件的图层**（按钮底、文字、焦点环、图标……，按真实叠放顺序）。
- 半透明（比如禁用时的 45%）已经设成图层不透明度，不是烤死在像素里。
- 「底色」图层只是示意这个组件在游戏里放在什么颜色上，不属于组件本身。

## 要知道的限制

- **文字是位图图层**，不是可编辑文字。字体是代码里的 `LXGW WenKai`（霞鹜文楷），这台机器没有这个字体，导出时回落成了 Noto Serif SC。想要原字体效果：装上文楷，重跑一遍导出；或者画师直接用文楷重打文字盖上去。
- 状态图（悬停、按下、焦点）是用浏览器强制触发的，和真实交互一致。动画只导出静止的第一帧（提交中的扫光、闪烁状态）。
- 头像用的是 `packages/shared-ui/lxh/ai-avatars` 里现有的 5 张占位头像，图层上是普通位图，可直接替换。
- 种族网格、谱系树这类大组件，部件很多，图层也多（几十层）。
- 站点全局栏（`site-nav.js`）和品牌标没做进 PSD：全局栏由脚本拼出来、含登录状态，品牌标 svg 已放在 `icons/svg/brand-iridescently-mark.svg`。

## 改完怎么回到产品里

PSD / PNG 是**设计稿**，页面用的仍然是 `packages/shared-ui/lxh-ui.css`，改图不会自动改线上。回写有两条路：

1. **只改了颜色**：改 `tokens/色板.psd` 里色块图层的颜色，然后运行
   ```powershell
   $env:IRIDESCENTLY_OPS_ROOT = '<工作区>\operations'
   python "$env:IRIDESCENTLY_OPS_ROOT\lxh-ui-kit\token_diff.py" 改好的色板.psd
   ```
   会列出哪些 `--lxh-*` token 从什么色变成了什么色。把这个列表交给开发（或 AI），改 `lxh-ui.css` 顶部的 token 就行，所有组件跟着变。
2. **改了形状、间距、造型、图标**：把改好的 PSD / PNG（和图标的 svg）放回同名位置，告诉开发哪个组件改了什么；开发对照图改 CSS / SVG。图标 svg 可以直接替换 `LXHUI.ICONS` 里对应的那条。

## 重新导出（开发用）

```powershell
$env:IRIDESCENTLY_OPS_ROOT = '<工作区>\operations'
python "$env:IRIDESCENTLY_OPS_ROOT\lxh-ui-kit\export.py"              # 全量，输出到本目录下的 lxh-ui/
python "$env:IRIDESCENTLY_OPS_ROOT\lxh-ui-kit\export.py" --only 01 05 # 只导某几组
```

需要：Python + `playwright`、`psd-tools`、`Pillow`、`numpy`，以及本机 Edge 或 Chrome。要加组件或状态，在 `<工作区>\operations\lxh-ui-kit\kit.html` 里加一行 `add(...)`。导出后看 `lxh-ui/导出报告.txt`：它把各层叠回去与整图逐像素比对，平均差 < 1 视为一致。
