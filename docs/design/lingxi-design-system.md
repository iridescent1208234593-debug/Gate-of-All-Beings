## 方向

自然、灵动、温柔、克制、现代幻想。素材来自光、苔、雾、纸、水纹、萤火、叶。**不用**：水墨、印章、卷轴、祥云、金边、书法大标题、修仙境界大字（这些会把画面带成古风修仙手游）。统一的是语言，不是版式：艺术展示页疏朗、社区页温暖、管理页紧凑、游戏页让画面做主角。

语义令牌（`--ling-bg/surface/text/accent/...`）在浅色是纸，在 `data-ling-theme="night"` 或 `auto`+系统深色时切换为夜林。页面自己的主题开关（`hx_theme` cookie，`packages/shared-ui/theme.js`）继续负责写这个属性，不另造主题状态。

## 字体与排版

- 正文 `--ling-font-body`：思源宋体 / Noto Serif SC；界面控件 `--ling-font-ui`：系统无衬线；手写感标题与便签 `--ling-font-hand`：霞鹜文楷（缺字时回退宋体）。
- 字号：12 / 13 / 15（正文）/ 18 / 22 / 2xl（24–32 流式）/ display（32–56 流式）。正文行高 1.8，中文字距 .04em，小标题（kicker）.22em 全大写拉丁。
- 舒适阅读宽度 `--ling-measure: 36em`。被阅读的文字在 390 宽手机上不小于 13px；可点文字不小于 14px。
- 英文只作小标题或副标题，不和中文抢主位。

## 间距、栅格、形状

- 4px 基准：4 / 8 / 12 / 16 / 24 / 32 / 48 / 72。页边 `--ling-gutter`（16–48 流式）。
- 圆角 6 / 10 / 16 / 胶囊。便签使用「左上小、其余大」的不对称圆角，像被胶带贴住的纸。
- 触控目标不小于 44×44（`--ling-tap`）。
- 阴影三级：贴面（列表卡）、浮起（弹层）、悬空（引导便签、对话框）。不使用大面积毛玻璃；`backdrop-filter` 只用于导航条和角落按钮这类小面积。

## 动效

| 令牌 | 值 | 用途 |
|---|---|---|
| `--ling-ease-travel` | `cubic-bezier(.55,0,.18,1)` | 位置之间的移动：起步干脆、落位很软 |
| `--ling-ease-out` | `cubic-bezier(.22,.8,.24,1)` | 出现、展开 |
| `--ling-ease-settle` | `cubic-bezier(.34,1.36,.5,1)` | 只用于完成反馈的轻微回弹 |
| `--ling-dur-1/2/3/4` | 120 / 220 / 420 / 720 ms | 按压 / 小状态 / 面板 / 移动 |
| `--ling-dur-hold` | 900 ms | 关键信息落定后的停留 |

原则（取自 video-shotcraft 审美准则并按交互界面改写）：

1. **手先到，眼再跟**：指示物（引导灵光、光标）先出发、先落位，画面和文字随后稳定。
2. **光决定看哪里**：用柔和的光池压暗四周，不用整屏黑遮罩；高光一个时刻只给一个主角，不群发光效。
3. **一个手法只当一次主角**：同一页里飞入、翻转、展开各用一次；重复的信息直接删掉。
4. **关键信息落定后要呼吸**：完成反馈之后停留约 1 秒再走。
5. **不强迫等待**：任何动画期间都能点击、滚动、关闭；`prefers-reduced-motion` 或 `data-ling-motion="reduced"` 时移动变为瞬时，内容不变。
6. 禁止：粒子堆叠、大面积泛光、频繁全屏缩放、机械式卡片齐飞、不能跳过的长动画。

## 引导模式（新人引导三章）

| 章 | 位置 | 进度 owner | 实现 |
|---|---|---|---|
| 认识世界 `world` | 会馆首页（主站根域落地页即此页） | Account / 访客浏览器 | `apps/huiguan/onboarding.js` 顺序七处 |
| 建立身份 `identity` | 会馆登记表、登录、同人画廊 | Account / 访客浏览器 | 同上，情境提示 |
| 开始生活 `life` | LAB 游戏 | LAB 玩家 | `life_guide.gd` 情境提示 |

视觉部件：灵光（一点会呼吸的光，飞向目标时走一段轻弧）、手绘光环（略带抖动的一笔描边，0.68 s 画完）、纸便签（米色纸、细噪点、一条嫩绿胶带、手写标题）、光池（目标周围全亮、四周最多压暗 38%）、完成反馈（两片叶子展开一次）。手机上便签停靠在底部（网页）或顶部（游戏）。

交互：不开模态、不锁滚动；`Esc` 暂停；每张便签都有「稍后 / 收起」和「不需要引导」；暂停后角落留一点灵光，已完成或跳过后从「更多 · 新手引导」（网页）或顶栏「新手引导」（游戏）重新查看。老账号、老浏览器、老玩家不被带着重走。
