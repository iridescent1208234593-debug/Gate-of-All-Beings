# design-reference · 界面参考素材

设计组件时对照的截图与样稿：官方游戏界面截屏、聊天和小红书截屏、手绘草稿等。这里**不公开、不进站点发布快照**，只给设计和开发参考。

| 目录 | 内容 |
| --- | --- |
| `lxh/`（根目录） | 未分类截屏：`QQ_*`、`mmexport*`、`Screenshot_*_xhs`、`Camera_*` 等原始文件名 |
| `lxh/ui/` | 界面部件参考：头像框、气泡、计数条、名牌、种族选择格等 |
| `lxh/chars/` | 角色参考图 |
| `lxh/scenes/` | 场景参考图 |
| `lxh/world/` | 世界观设定、领地、图标参考 |
| `lxh/ai-avatars/` | 未被采用的种族头像候选 |

2026-10-17 从 `shared/shared-ui/lxh/` 原样移来（`git mv`，历史可追溯），保留原子目录结构。

## 约定

- 新的参考图放这里；只有被代码真正引用的图片才进 `shared/shared-ui/lxh/`（会公开发布）。
- 要把某张参考图用到页面上：先按用途改成小写英文短横线文件名，再移到 `shared/shared-ui/lxh/<用途>/`，并在样式指南登记。
- 含他人账号、聊天内容或未授权图片的截屏只留在这里，不要移入公开目录。
