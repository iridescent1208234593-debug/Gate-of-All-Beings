# 文案与世界观组

文案按表格交，一行对应游戏里的一次互动，程序可以直接导入。原型里现有的 40 多条文字是程序写的占位，需要文案组重写。

## 标准

- **长度**：
  - 一个对话框一段话，不超过 60 个字，超过就拆成下一段。
  - 物件描述 20 到 60 字。
  - 路牌 20 字以内。
- **语气**：
  - 短句，有画面感。写看得到、听得到、摸得到的东西，少用形容词堆砌。
  - 符合《罗小黑战记》世界观，不写网络梗和现实品牌。
- **同一个东西可以写几种反应**：第一次点和之后再点说的话可以不同，也可以跟玩家先前做过的事有关，例如「跟奶鼠聊过之后」。每种反应写一行，注明触发条件。
- **主角是玩家自己的 OC**：
  - 文字里不给主角起名、不定性别、不替主角说话。
  - NPC 用「你」来称呼主角。
  - 需要说出名字的地方，写成 `{玩家名}`，程序会替换。
- **官方角色**：只在关键地点偶尔出现，台词要符合原作人设，交稿前自己核对一遍。
- **AI**：按 [general.md](general.md) 的 AI 使用规则执行。
- **表格列**：按下表填写。编号由策划和程序给，形式是「地图.物件」，写好后就不要再改。

## 首批任务

- [ ] P0 重写主世界现有的全部互动文字，清单由程序导出成表格给你们：
  - 门庭、篝火、守火老人
  - 奶鼠、花园三种花、青蛙
  - 河、木桥、树、蘑菇
  - 五块路牌、西木会馆、虹
- [ ] P0 开场进门的三句话；新手提示，讲怎么走、怎么调查、怎么打开手记。
- [ ] P0 会馆引导 NPC 的首轮对话，3 到 5 段。
- [ ] P0 设定校对清单：哪些名词、地名、称呼是固定的，哪些不能用。
- [ ] P1 第一批奇遇事件的选项和结果，用同样的表格格式。
- [ ] P1 区域背景、物品描述、任务文本；玩家投稿 NPC 的审稿标准。

## 验收

- 表格导进游戏后不用人工改格式，对话框里没有溢出、没有缺字。
- 每个可以点的东西都有文字，没有一条还是占位。
