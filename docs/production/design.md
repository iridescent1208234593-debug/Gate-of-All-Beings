# 总策划组

总策划要先写一份首个可玩版本的范围单，写清这一版做什么、不做什么，其他组按这份单子排活。

这一组也负责维护 `docs/production/` 下的全部文件：细改各组标准，并把「待策划定」的地方定下来。

## 建议的范围（待策划定）

**做**：

- 四张图：主世界、西木会馆、林缘、会馆小院。西木会馆只做门口和一幅地点画面。
- 玩家能在图里走、调查、对话、拾取，可以切换昼夜。
- 退出后再进来，位置和已经做过的事还在。
- 主角是玩家自己的 OC。首版用通用小人，显示 OC 的名字和头像，做法见 [art.md](art.md)。

**不做**：战斗、卡牌对战、死亡复活、交易、多人同屏、经济数值。这些等可玩版本通过后再单独立项。

每个功能写成一张卡片，固定五项：

1. 目的，一句话。
2. 玩家的操作步骤。
3. 系统的反应。
4. 会记下什么状态。
5. 怎样算做完。

## 首批任务

- [ ] P0 写可玩版本范围单，参考上面的建议。
- [ ] P0 写四张图的互动点清单，每个点写：

  现在主世界有 25 个点，可以在这个基础上增删。
- [ ] P0 定玩家 OC 怎样变成游戏里的小人（三种做法见 [art.md](art.md)）。

  - 移动方式（现在是点哪走哪）
  - 拾取的东西放在哪里
  - 存档存什么、什么时候存
- [ ] P1 奇遇的触发条件、分支和奖励。
- [ ] P1 成长、卡牌、任务的完整流程。
