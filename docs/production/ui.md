# UI/UX 组

界面以横屏 1280×720 为基准设计，手机和电脑共用一套，尽量少挡地图。

账号、手记、名册、存档已经在网站上，游戏里只做入口，不重做一套。

## 标准

- **画布**：
  - 设计稿用 1280×720。
  - 另外画两张对照稿，看布局会不会跑位：
    - 手机横屏，约 812×375，左右要避开刘海。
    - 宽屏，1920×1080。
- **点击区**：按钮和可点的东西在 1280×720 下至少 64×64，相邻两个间距至少 12。
- **字体字号**：
  - 用思源黑体（Noto Sans SC，OFL 开源）。
  - 正文 22，标题 28，小字不小于 18。
  - 如果想用其他字体，先确认可以免费商用、可以嵌入网页。
- **颜色**：
  - 定一套颜色表，每色给出色值：底色、面板色、主色、强调色、文字主色、文字次色、成功、警告、错误。
  - 文字和底色对比度至少 4.5 比 1。
  - 风格跟着画风样张走，用自然、纸质、手记的感觉，不要科幻光效。
- **状态**：每个按钮和选项都要画全六种状态：普通、悬停、按下、选中、不可用、加载中。
- **交付格式**：
  - 用 Figma 交付，组件要分好层、命名。
  - 面板和按钮的背景切成九宫格 PNG，并写明四边留多少像素不拉伸。
  - 图标交 64×64 和 128×128 两个尺寸的透明 PNG。
- **一次一个面板**：同一时间只打开一个大面板，不叠弹窗。对话框在屏幕下方，占高度不超过三分之一。
- **操作方式**：每个操作都要同时支持点触和鼠标。键盘快捷键是附加的，不能成为唯一的操作方式。
- **AI**：按 [general.md](general.md) 的 AI 使用规则执行。

## 首批任务

- [ ] P0 **地图界面**：地点名、昼夜切换、缩放、「调查」按钮、菜单入口。现在原型里用的是系统默认按钮。
- [ ] P0 **对话框**：角色名、立绘位（左或右）、正文、继续提示、最多 4 个选项。另外还要画一个只有物件描述、没有立绘的版本。
- [ ] P0 **交互提示**：在可以点的物件头上显示一个小标记，分调查、对话、拾取三种。
- [ ] P0 **地点画面**（如门庭、西木会馆）：全屏画面，加一块文字面板和按钮。
- [ ] P0 **主菜单、暂停菜单、加载画面**。加载画面可以用车库老师的灵体加载动画。
- [ ] P0 **入口按钮**：手记、名册、背包的入口。点了会打开网站的面板，游戏里不另做界面。
- [ ] P0 **组件库**：统一的按钮、面板、弹窗、选中态。
- [ ] P1 **其他界面**：
  - 灵卡、牌录
  - 任务、成就
  - 设置（包括音量分项）
  - 地图导航

## 验收

- 程序不用另外问尺寸，就能照着做出来。
- 在手机横屏和宽屏上都不跑位。
- 点触和鼠标都能完成所有操作。
