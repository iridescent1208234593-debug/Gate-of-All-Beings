## 两类故障的真实根因

### 会馆展示

`show.html` 通过 `/api/huiguan/get-character?code=...` 请求展示 HTML。`/api/huiguan/` 是已有合法别名，并非本次错误。

配色海报在 SQLite `posters` 中按海报 ID 保存、在公开画廊使用 `poster-<id>`。旧展示 API 只查 `characters.json` 中的 OC 设表，因此所有海报码均返回「角色不存在」。`poster-43` 的真实海报图片及公开记录均存在；没有丢失图片。

67 条公开画廊记录的基线：60 条 OC 展示成功、6 张海报失败、1 条 OC 失败。海报码为 `poster-8/14/21/42/43/44`。失败 OC 的原始设表已不存在，但公开画廊保留了真实资料字段；不删除或捏造该用户的设表。

修复在原展示 API 中增加实体解析：继续优先使用 OC 原始展示 HTML，海报按自己的 ID 与公开/所有者权限读取；原始设表缺失时只显示已公开的画廊资料，并标明来源状态。不存在、未公开、非所有者的私有海报均不泄露。未覆盖任何数据库或用户文件。

### 本机小游戏深层入口

PC 网关把 `/app/shell/m/<key>` 映射到 `server/app`，但通用 SPA 回退总是使用该目录的 `index.html`。真正入口是 `server/app/shell/index.html`，因此包括省省射击在内的 8 个深层玩法入口都返回 404。香港统一门户原有映射正确。

修复明确让所有无扩展名的模块壳路径使用现有 `shell/index.html`；脚本、样式、玩法本体仍使用原部署目录。覆盖 Cards、Management、Ecology、Juling、Slay、Softie、AEON、省省射击。没有改游戏引擎、账户、存档或兑换规则。

## 故障恢复行为

- 统一组件提供换服务器重试、重新加载、返回门庭。
- 保留完整路径、查询参数、锚点；显式节点选择不会被 PC 导航拦截重新改回原节点。
- 一次限时健康探测提示另一门户是否可达；玩家手动选择，没有无限重试或重定向循环。
- 模块壳检查 HTTP 状态及入口类型，原挂载失败清理仍执行。未知玩法、缺失模块、iframe 入口不可用均给恢复操作。
- 源站游戏导航 404 / 502 等保持真实状态。nginx 能在应用停止响应时独立提供恢复页面和恢复脚本；API 故障保持 JSON 502，不注入 UI。
- 香港 Dispatcher 会剥离静态路由前缀；恢复逻辑使用原始 HTTP 请求目标，避免 `/app/modules/...` 被改写成 `/...` 后误判为普通页面。此缺口在正式浏览器验收中发现，已通过真实分发链回归后补发。
- 节点共享香港 API；共同后台故障时换页面节点不能保证恢复。设备本地草稿与未上传进度不自动跨域转移。

## 带宽优化与实测数据

射击两张结算插画合计 69,024 字节，只在出现对应结局时读取，不再占用首屏预加载或阻塞开始游戏。图片字节、尺寸、格式及动画未改变。此处 88.7% 仅指该组首屏图片，不是整个游戏页面。

香港 Python 返回 JS 的 MIME 是 `text/javascript`，旧 nginx gzip 列表缺少该类型，源站实测 JS 为未编码的 16,699 字节。候选补齐类型并使用 gzip level 5，也覆盖 TTF/OTF/WASM；没有叠加服务器 Brotli/zstd 模块。

PC 原站此前不做文本编码。候选在 HTML 注入完成后压缩，支持 gzip q 值协商、Vary、表示对应的 ETag、304 和 HEAD，最多缓存 8 份、每份不超过 8 MiB 的表示。Range/图片/音频/已压缩 WOFF2 不走此压缩路径。HTML 始终不存储缓存；可变代码重新验证，内容哈希资源继续一年 immutable。

### 构建层、服务器层、CDN 层

- **构建层：** 现有 Vite 游戏包已有生产 minify、模块拆分及哈希资源名。本轮没有手工 minify 源码，也没有构建 Claude 的未完成代码。
- **服务器层：** nginx 修正 MIME 缺口；PC 使用标准库 gzip 和验证缓存。压缩解码后的字节与源文件一致，字体字形无变化。
- **CDN 层：** 基线已实测 zstd/gzip，多个公共 JS/CSS 为 HIT。比如展示页 3,815→2,112 字节、展示导出 JS 5,493→2,529 字节，最大 TTF 6,497,568→3,938,849 字节（zstd）。保持现有协商，不新增重复压缩规则，不宣称这些已有收益属于本轮新增。

此外观察到 PC 原站可变代码的 `no-cache, max-age=0, must-revalidate` 在 CDN 返回中被改为 `max-age=14400, must-revalidate`。现有 Tunnel 证书查询 Browser Cache TTL / Cache Rules 均返回 Cloudflare 403，无法核实或修改具体覆盖规则。本轮对改动脚本使用新版本 URL，未擅自全站清缓存；上表 PC 缓存值是原站策略，不能声称 CDN 已完全遵循。

### 图片、字体与重复资源审查

扫描范围：已构建游戏模块、共享 UI、首页产物与图库、省省射击和会馆 gate 资源。记录 PNG 288 MB、JPEG/JPG 56.8 MB、WebP 1.45 MB、TTF 16.3 MB；未发现该范围的 AVIF。它们是磁盘总量，不是首屏必下载量。

射击背景、角色、敌人和子弹已经使用 WebP。画廊已有半径 3、并发 2 的窗口加载及释放机制，实际仍获取原图后在浏览器缩到 1536 纹理；大原图存在未来生成响应式衍生图的机会。本轮保持原图和画质，未对整库有损转码。

三个 CJK 字体仍是 TTF，尚未做 WOFF2 或分片/子集。没有删除字形或更换字体，字体加载仍为 `font-display: swap`。SVG 体积很小，不为它们增加优化依赖。发现约 1.29 MB 的相同字节构建副本，部分可能被旧页面或嵌入生态路径引用；本轮未擅自清理旧哈希文件。

跨站导航及 CSS 继续复用既有公共 URL，没有复制另一套公共资源。新增恢复 JS 为 4,423 字节，gzip 2,042 字节。
