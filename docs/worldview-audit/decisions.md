# 主创决定与待考证清单

本文件分三部分：

1. **主创最终决定（D01–D18）**：2026-10-26 由项目主创佳霖给出，全部已定，不再是待决事项。
2. **实现安排**：哪些在 PR #9 里完成，哪些留给后续单独的 PR。
3. **需要原作资料确认**：原作事实还不确定的地方，资料确认前不改、不删。

条目编号对应 [audit-report.md](audit-report.md)。总规则见 [style-guide.md](style-guide.md)。

## 通用原则（适用于所有后续实现）

- **世界观层与机制层分开。** 原作事实以可确认的资料为准；游戏为了玩法做的拆分、组合、数值、阶段都标为“本作规则 / 本作分类 / 本作演绎”。
- **代码里的单一数据来源不等于原作事实来源。** `packages/shared-types`、`packages/shared-data` 负责“项目里只有一份”，不负责“原作是什么”。
- **存档兼容优先。** 只改玩家可见语义；内部字段（`seeker`、`relic`、`realm_*`、存档 key 等）只要不显示给玩家，就保留兼容，另开技术债处理。
- **不删除成熟玩法，不新增原作误设，不给官方角色加戏。**
- **说明要简短。** 在模块或区域层说一次即可，不要每个页面、每句话都堆免责声明。

## 一、主创最终决定

### D01 项目名「众生之门」 · 保留
- 不改项目名。
- 定位：《众生之门》是《罗小黑战记》的同人项目。项目名与原作中的“众生之门”同名，但本站不是原作的官方游戏，也不是官方还原。
- 在合适的位置（如门场景、关于页）加一句简短说明，不要每页都放。

### D02 重生之门的修仙体系 · 保留机制，逐步去掉世界观包装
- 炼气、筑基、金丹、元婴、化神、渡劫等，不能再用来给原作角色和地点划分世界观等级。
- 玩家可见层逐步改为：试炼阶段、门内规则、旅程层级、中性的成长指标。
- 保留旧存档 key 和内部兼容字段，不能为了改文案破坏存档。

### D03 一念仙途 · 保留，与核心世界观分离
- 定位为外围的、独立的修仙题材玩法，并明确说明它与《罗小黑战记》世界观没有直接关系。
- 不删除这个玩法，也不再把它包装成“灵质体系本身”。

### D04 轮回 / 魂灵不灭 · 只作为重生之门自己的叙事
- 可以作为重生之门的叙事规则或传说，但不能当作整个罗小黑世界的客观真相。
- 旁白禁止使用“世界真相”“轮回的真相”“魂灵永远不灭”这类给原作下结论的口吻。
- 可以通过门灵、传说、门内规则或角色自己的理解来表达。

### D05 worldview.json 里角色的修仙境界 · 长期改为中性的内部 balance tier
- 只用于数值平衡，不向玩家显示，不再把原作角色按修仙境界分级。
- PR #9 不做高风险的 schema 迁移。技术债记为：`realm_*` 改为中性的内部 tier（见 copy-debt.md T11）。

### D06 原作地点映射到修仙境界 · 取消
- 地点仍可以作为路线、楼层、关卡或试炼节点。
- 不能再建立“罗家岙 = 炼气”“某会馆 = 化神”这类对应关系。

### D07 聚灵的「仙人 → 神 / 封神」 · 取消这条必经的线性成长阶梯
- 成长阶段改为描述灵的形成、聚合、稳定与成长状态。
- 不再建立“妖精 → 得道 → 仙人 → 神”这种看起来像原作世界统一物种等级的链条。
- 新阶段的具体名称以后单独润色，不在 #9 里定死。

### D08 聚灵中掠夺原作角色 · 停止
- 原作角色不再作为可以被豪夺、掠夺的资源型 NPC。
- 原作角色可以以来访、请教、切磋、结伴或固定事件的形式出现。
- 如果玩法需要“掠夺”机制，改由原创 NPC、抽象事件或原创资源对象承担。

### D09 灵境会馆随机小妖使用原作角色名 · 改为原创或通用名字
- 随机池只使用原创名字或通用名字。
- 原作角色只出现在专门设计的固定剧情或来访事件中，不再让无限、老君、小黑等以随机路人的身份反复出现。

### D10 无限 Boss 的原创招式 · 保留玩法，区分演绎与原作
- 原作能力不等于本作的战斗演绎。“剑域”这类名称不要包装成原作的官方招式。
- 二选一：改成更贴合无限已知能力体系的演绎名，或者明确标注“本作演绎 / 原创招式”。

### D11 OC 页「第29集 — 虹之间」 · 修改（本 PR 已完成）
- 不再使用像官方动画剧集编号的格式，也不再使用“罗小黑战记 · X”这种官方作品式标题。
- 已改为：标题「虹之间」，副标题「三足乌后裔的收藏（同人短片）」，角标“EP.29 4K”改为“4K”。视频文件名不对玩家显示，保持不变。

### D12 「灵质」作为货币 · 逐步停止
- 不再把“灵质”当作普通的可消费货币。“灵质空间”“灵质力”尽量保持原作语义。
- 资源按用途拆分为灵材、能量和各玩法专属的资源，不要把所有东西统一改名成一种新的万能货币。
- 已有存档字段继续兼容。

### D13 玩家身份与长期记录 · 门客 / 灵记
此前的“修行者 / 魂灵印记”和“过门人 / 门印”**全部作废**。

**门客**：指曾推开众生之门、被门庭接纳的来访者。这是本站原创的身份称呼，**不是**种族、修行等级、宗门身份、轮回身份或力量等级。

**灵记**：门客在旅途中留下的记录，可以承载相遇、选择、成长、同行关系、世界的回应和旅途经历。这是众生之门原创的记录概念，**不能**解释成灵魂本体、灵魂碎片、转世凭证、轮回印记或力量等级。

实现原则：只改玩家可见的语义，不为了改名去重构存档契约。`seeker`、`relic`、save、profile 等内部字段只要不暴露给玩家，就继续兼容，后续另开技术债处理。

### D14 万剑归一 · 跟随 D10
- 不作为“无限的原作正式招式”。
- 玩法效果可以保留，显示名改为明确属于本作战斗演绎的名称。

### D15 能力系数量 · 以可靠的原作资料为准（UI 部分本 PR 已完成）
- 世界观层不再同时出现互相矛盾的“六大 / 七大 / 八大”体系。原作为六大系：御灵、锁御、造物、生灵、心灵、空间。
- 游戏额外拆出的类别要明确标为“本作分类 / 游戏规则”。重生之门 UI 已改为“六大系与强化、治愈分支（本作分类）”，见 F23。
- 同时推进 T01：能力数据最终要形成真正的单一数据来源，但代码里的单一来源不能代替原作事实来源。

### D16 系别与五行的映射 · 保留，标为本作规则
- 可以保留这套游戏机制，但必须写明属于“本作演武规则 / 本作战斗规则”，不能写成罗小黑世界的客观能力法则。

### D17 治愈与空间互斥 · 从世界观和 OC 登记规则层取消
- 取消人设登记（huiguan）里的硬性互斥。
- 如果某个玩法为了数值平衡确实需要互斥，只放在该玩法内部，并写明这是玩法平衡规则，不是原作世界的限制。

### D18 同行者引言 · 允许同人台词
- 不需要在每句话上加醒目警告，在模块或区域层标明“同人演绎”即可。
- 真正引用原作原句的内容另外注明出处。
- 不要把项目自己写的台词包装成原作原台词。
