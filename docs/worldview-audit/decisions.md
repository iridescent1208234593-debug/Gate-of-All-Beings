本文件分两部分：

- **需要项目主创确认**：涉及众生之门的核心原创设定，改不改、怎么改都由主创决定。每项给 1–3 个方案，第一个是推荐方案。
- **需要原作资料确认**：项目里写了，但手头资料（灰机 wiki、萌娘百科等二手资料）不足以判断是否符合原作。资料确认前不改、不删。

## 一、需要项目主创确认

### D01 项目名「众生之门」与原作内同名游戏
原作漫画中，《众生之门》是一款 VR 游戏，山新在漫展拿到游戏机，小黑、小白、阿根一起进入。`apps/slay` 的遭遇战里也已经有“众生之门玩家”。

1. **（推荐）把同名变成设定**：在门场景/关于页写一句“本站借用了原作中那款 VR 游戏的名字，是同人创作，不是原作游戏的还原”。保留品牌，消除误认。
2. 保留名称，但在所有对外标题统一加“同人”后缀（本 PR 已对重生之门这样做）。
3. 改项目名。代价最大，不推荐。

### D02 重生之门的修仙境界体系（炼气→渡劫、修为、道心、福缘）
1. **（推荐）保留机制，换包装**：境界名改为灵质力相关的中性阶段（如“初醒 / 通灵 / 御灵 / 化形 / 归真”），修为→灵质力，道心→心境，福缘→机缘。机制与存档 key 不动。
2. 保留修仙体系，但在“灵质修行”页明确写“这是重生之门里的试炼规则，不是罗小黑世界的设定”。
3. 维持现状。

### D03 内嵌的「一念仙途」修仙卡牌（约 3.2 万字，无罗小黑内容）
1. **（推荐）从“灵质修行”页移到“外围玩法”**，入口写明“独立的修仙题材小游戏，与罗小黑世界观无关”。
2. 保留在原处，加同样的说明。
3. 移除嵌入（用户要求不删成熟玩法，故不推荐）。

### D04 轮回 / 魂灵不灭作为“世界真相”
涉及：`win-screen.js`「轮回的真相如潮水涌来——魂灵从未真正消散」、`dungeon.js`「可窥见轮回的真相」、`soul-legacy.js`「超脱轮回，凌驾生死」、众生牌录 hero quote「魂灵入门，前尘尽忘」、成就描述。
1. **（推荐）把“真相”改成“重生之门的规则”**：例如“在重生之门里，散去的灵会再一次聚起”。不对原作世界下结论。
2. 保留轮回叙事，但以角色口吻（传说、门灵的话）出现，不用旁白宣布。
3. 维持现状。

### D05 worldview.json 中每个角色的修仙境界（realm_key / realm_name）
1. **（推荐）改名为与境界无关的数值档位**（如 `tier: 1–9`），只供平衡用，永不显示。
2. 保留字段，但在数据文档里写明“仅用于数值平衡，禁止在 UI 显示”。
3. 删除字段。

### D06 原作地点映射到境界（罗家岙=炼气 …）
随 D02 决定。若 D02 选方案 1，地点只表示“第几层”，不再带境界名。

### D07 聚灵的阶段终点「仙人 → 神」「封神！超脱轮回」
1. **（推荐）阶段改为灵的聚合程度**：灵 → 精灵 → 妖精 → 大妖 → 灵脉（终局）；去掉 ☯ 与“封神”。
2. 保留“仙/神”，但写成稀有结局而非升级必经。
3. 维持现状。

### D08 聚灵里原作角色可被“克伐/豪夺/掠夺”
1. **（推荐）原作角色只作为“来访/指点”的事件出现**，可交互动作改为“请教/切磋/结伴”。
2. 被掠夺对象换成原创 NPC。

### D09 灵境会馆随机小妖直接使用官方角色名
1. **（推荐）随机池只用原创名**，官方角色只在固定剧情中出现。
2. 官方角色保留在池中，但加“来访”标签并降低出现率。
3. 维持现状（不推荐，会增加官方角色戏份）。

### D10 无限 Boss 的「剑域」/ D14「万剑归一」
1. **（推荐）保留为原创招式，但在技能说明里标“本作原创”**。
2. 改为基于原作可确认能力（金属系操控）的描述，如“金刃领域”。

### D11 OC 页视频标题「罗小黑战记 · 灵质空间 / 第29集 — 虹之间」
1. **（推荐）去掉“第29集”和“罗小黑战记”前缀**，改为「虹之间 · 三足乌后裔的收藏（同人短片）」。
2. 保留集数格式，但加“同人”字样。

### D12 「灵质」作为可消耗资源/货币
1. **（推荐）资源改叫“灵气/灵材”**，“灵质”只用于“灵质空间、灵质力”。
2. 保留，但在名词表里写明“本作中灵质也指可收集的灵材”。

### D13 玩家身份「修行者 / 魂灵印记」
1. **（推荐）改为“过门人 / 门印”**，与“众生之门”品牌呼应，不带修仙和轮回含义。
2. 保留“修行者”，去掉“轮回”说明。

### D15 能力系数量（六 / 七 / 八系）
原作资料里常见“御灵、空间、生灵、强化、心灵、造物、锁御”等说法，各资料划分不一。
1. **（推荐）以 `packages/shared-types/world.js` 为唯一来源**，UI 不写数字（不说“八大”），只列出名称。
2. 保留“八大系”，但标为“本作分类”。

### D16 / D17 系别↔五行映射、治愈与空间互斥
都是原创平衡规则。推荐在 UI 上写成“本作规则 / 本站登记规则”，不写成世界法则。

### D18 同行者引言
1. **（推荐）引言区加“同人台词”小字**，或改为第三人称描述。
2. 逐条核对原作，能对上的保留，对不上的改写。
