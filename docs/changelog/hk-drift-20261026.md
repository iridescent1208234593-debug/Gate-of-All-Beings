# 香港生产与 trunk 的差异台账（2026-10-26）

香港生产在 2026-10-24～10-26 由 DSH Agent 直接发布了一批修复与功能（记录：[PRODUCTION_CHANGES_20261026.md](PRODUCTION_CHANGES_20261026.md)，原分支 `docs/production-changelog-20261026`）。它们基于旧布局（`f31e7d8`），不在 trunk 里。本表逐条记录移植状态；trunk 部署到香港之前，表里每一行都必须是"已移植"或"决定不移植"。

DSH 的分支提交是"把线上文件整份提交到旧基线"，与基线的差异里混有线上已经存在、trunk 早已另行包含的改动（例如 10-24 安全加固）。移植时只取对应功能的语义差异，并按 trunk 的三根域规则改写；不直接套用补丁。
