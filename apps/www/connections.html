  11. 10/17 下午

    众生之门 · 门庭与形象

    门庭按卡牌双门（入世历练 × 重生之门，准备合流）、省省海滩射击、聚灵依次重排，每扇门换成游戏实拍画面，悬停展开演示与介绍；玩家形象支持多开与删除，种族分为人类 / 妖精 / 其他 → 种族 → 细分，并可写备注；返回门庭不再重复播放开场动画；电脑与手机的导航和布局一并整理。

  12. 10/17 傍晚

    一条导航连起三站

    节气画廊、西木会馆和众生之门共用同一条顶部导航，带在线状态、语言和账号，加载改为就地显示；品牌标重画成红绿蓝三颗像素小球；入世历练换成一扇森林大门，悬停播放战斗与地图，重生之门作为「爬塔篇」并入其中；新形象可以从开场完整走一遍。

  13. 10/17 深夜 → 10/18

    会馆共创与夜间修缮

    西木会馆加入编辑码、荣誉长老 / 妖王称号与审核，官方角色下多了同人画廊，可以点赞和评论，点赞收藏也有了小动效；头像裁剪偏移修正，保存时图片并行上传；修好发布后旧页面被缓存、服务器空转占满 CPU 的问题，并完成新一轮安全加固。

  14. 10/18

    顶栏与时间线小伙伴

    主站顶部导航换成轻薄磨砂玻璃；时间线旁住进三只陪项目长大的 AI 小精灵——Qwen 水豚、Codex 终端小机器人和像素 Claude，每个节点都标出是谁一起走过的。

  15. 10/18

    发布可见性与连接稳定

    修复发布后浏览器继续使用旧版模块资源的问题，也处理了连接重置后服务空转占满 CPU 的情况；会馆共创画廊和对应的安全修缮同步完成。

  16. 10/19 早

    扛住注册高峰

    注册高峰时服务器不再排队卡住，门户空转占满 CPU 的情况被压住；随后主站整体交给香港服务器承载。

  17. 10/19

    入世历练可以重玩

    战败也会带回掉落，同行者会受伤甚至陨落，5 小时后复活；打完可以直接走向重生之门。

  18. 10/19 晚

    众生之门 · 共同旅途

    手记成为众生之门的主界面：入世历练、重生之门和新加入的灵质修行共用同一份角色名册、灵卡目录和进度账本，重生之门的结算会回到公共资源里；修好灵质空间悟得词条时的报错，卡牌动效也改为从本站加载。

  19. 10/19

    众生之门共享进度

    把重生之门和灵质修行接入同一角色、卡牌目录与进度账本，补齐战败掉落、同行者受伤与复原等流程；游戏资源改为本站加载，并修复相关存档与结算问题。

  20. 10/20

    画廊、小游戏与双服务器

    修复会馆展示页和小游戏入口的访问问题，节气画廊增加账号互动与轻量 WebP 预览，并完善香港正式站与本机预览的发布管理；游客保存提醒也接入会馆登录态和众生之门建档流程。

  21. 10/21

    统一的按钮、输入框与弹窗

    会馆和众生之门共用的界面组件库整理了一遍：按钮、输入框、确认弹窗补齐悬停、按下、键盘焦点和加载状态，手机上的点按区域加大到 44px，文字对比度提高，弹窗可以用键盘操作；设计系统里新增了一页带实时演示的组件库。

  22. 10/21

    项目支持入口

    联系与鸣谢页加入 PayPal 项目赞助按钮，让想支持项目的朋友多一个方便的选择。

  23. 10/22

    会馆角色档案与轻量图库

    公开角色登记卡可以原位修改，官方角色与同人作品各归其位；图库列表优先加载轻量 WebP 预览，原图访问收紧到获准的查看方式。

  24. 10/22

    众生之门手机横屏引导

    开场与门庭按横屏体验整理，手机竖屏进入时会提示横过来，可尝试全屏横屏，也能随时切回竖屏继续使用。

  25. 10/23

    会馆账号称号防冒用

    注册和改名时拦截与官方角色重名的称号，并识别全角、大小写和不可见格式字符等变体，减少误认与冒充。

一起来会馆折腾吧

如果你也喜欢《罗小黑战记》，刚好喜欢画画、做像素、做网页或小游戏，或者只是常常冒出一些奇怪但有趣的点子，都欢迎来一起玩、一起做。这里不是工作室，也没有必须完成的进度，更像一群同好在会馆里慢慢搭一扇「众生之门」。

眼下最想遇到会画画的朋友：角色头像、卡面、场景、像素小人、界面图标，哪怕只画一张也很好。不画画也一样欢迎——做 UI 或动效、写网页和小游戏、整理设定和世界观、帮忙试玩找 bug、随口提个想法，都是在一起建这个地方。

这是一个长期、慢慢做的同人项目，代码也在一点点开源（主站画廊已经公开）。不用勉强自己，按自己的节奏来就好；被采用的作品和想法会在对应页面联合署名，并一直留在这一页的鸣谢里。想聊聊的话，微信、QQ 私信或者来 QQ 群 878029597 打个招呼就行。
