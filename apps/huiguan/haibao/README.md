# 配色海报

正式入口：`https://huiguan.iridescently.xyz/haibao/`。Portal 直接提供静态文件，无独立构建或发布步骤。

- `index.html`：画布、选色、图层编辑、本地草稿、会馆账户、配色 / 海报保存及 PNG 导出。控件 ID 保持原有约定。
- `editor.css`：页面编辑工具的视觉层级、预览舞台、分段导航、窄屏布局；不改变导出海报的样式或尺寸。
- `../image-upload.js`：文件上传、角色源图外置与 Blob PNG 下载。`../character-colors.js`：角色原色解析和展示主题。
- 本目录 PNG 和字体：画布素材，保留原文件。

操作依次为选配色、调整画面、保存 / 导出。古色需要点击应用；色环实时应用。组件编辑、云端保存和 PNG 导出沿用现有登录要求。桌面预览固定在左侧，手机为较小的顶部预览和下方操作区。预览尺寸不会改变导出尺寸 1080 × 1920。

2026-10-10 更新仅涉及页面文案与 UI。公网 Chrome 截图供用户验收；不向真实账户提交测试海报或配色。

2026-10-11：色环改为默认折叠的同页工具，首次展开才初始化交互，后续展开复用颜色和亮度。打开不覆盖当前草稿；调色实时反馈，收起不丢状态，刷新仍使用原有本地草稿恢复。色环固定尺寸，参数位于对应色环下方；沿用桌面左侧 / 手机顶部的 sticky 海报预览，不重建画布或跳转页面。

2026-10-13：云端保存与下载使用 `canvas.toBlob('image/png')`，固定 1080×1920，不乘设备 DPR。角色源图先上传成同源 URL；海报 PNG 作为独立文件传输，编辑 JSON 不再含原图 / 成品 Base64。默认业务 JSON 上限 8 MiB；海报 / 角色源图单个文件上限 8 MiB，multipart 另限定 metadata 256 KiB 与协议余量 64 KiB。图片格式、实际文件完整性和账户权限在服务端校验。

选色 HEX 就是双色背景上半的实际 RGB；下半白色渐变、竹叶及用户调节的图层透明度仍按其明确职责工作。移除了在整个双色背景上叠加的随机灰色 grain，避免原色被漂白。绑定本人角色保存海报后，角色保存数据与展示页都读取同一份 HEX。载入旧草稿 / 云端海报支持原 data URL 和文件 URL，并恢复已保存的位置与缩放；换海报或移除角色图不再复用旧图。
