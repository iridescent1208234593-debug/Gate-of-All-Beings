lxh-ui · 游戏界面组件库

众生之门、各游戏模块和会馆页面共用的游戏画面组件：HUD、面板、气泡、按钮、输入框、加载与出错。乳白圆角卡、赭金与灰绿双色按钮、深橄榄 HUD，配手写体。本页所有示例都由真实的 lxh-ui.css / lxh-ui.js 渲染，改源码后刷新就能看到。

接入

会馆页面用相对路径 /design-system/ui/（指向 packages/shared-ui 的 junction）；其他站点用 /shared/shared-ui/；React 模块用工作区包 @lxh/shared-ui。只要样式不要脚本也可以，所有组件都能手写 HTML。

<link rel="stylesheet" href="/design-system/ui/lxh-ui.css?v=20261027z">
<script src="/design-system/ui/lxh-ui.js?v=20261027z"></script>

// React / Vite 模块
import '@lxh/shared-ui/lxh-ui.css';
import '@lxh/shared-ui/lxh-ui.js';   // 之后使用 window.LXHUI

Token

两层 token：--qc-* 属于会馆和站点页面（design-system.css），--lxh-* 属于游戏画面（lxh-ui.css）。危险色和触控高度两者同源：--lxh-danger 引用 --qc-danger。色值从页面实时读取，点一下复制 var(--…)。

按钮 .lxh-btn

官方斜切平行四边形按钮，文字放在 <span> 里反向回正。「是」用赭金，「否」用灰绿，破坏性操作用赭红；浅色底上的次要操作用 --ghost。按钮底色比基础色深一档，保证乳白字对比达到 4.5:1。按 Tab 可以看到焦点环。

变体 状态 
<button type="button" class="lxh-btn lxh-btn--yes"><span>是</span></button>
<button type="button" class="lxh-btn lxh-btn--no"><span>否</span></button>
<!-- 变体：--yes · --no · --danger · --ghost；尺寸：--sm -->
<!-- 提交中：aria-busy="true" 并 disabled；文字保留，底部出现扫光 -->

const btn = LXHUI.button({ text: '提交', variant: 'yes', onClick: save });
LXHUI.setBusy(btn, true, '正在提交…');   // 结束后 LXHUI.setBusy(btn, false)

输入框 .lxh-field · .lxh-input

乳白槽位，聚焦时青玉描边加淡晕。校验失败设 aria-invalid="true"，错误文字用 .lxh-field__err 并通过 aria-describedby 关联。字号 16px，iOS 聚焦时不会放大页面。深色表面用 --dark。

<label class="lxh-field" for="nick">
  <span class="lxh-field__label">昵称</span>
  <input class="lxh-input" id="nick" aria-invalid="true" aria-describedby="nick-err">
  <span class="lxh-field__err" id="nick-err">最多 12 个字</span>
</label>

const f = LXHUI.field({ label: '昵称', placeholder: '给灵起个名字', hint: '最多 12 个字' });
f.setError('这个名字已经有灵在用了');   // f.setError('') 清除；f.input 是 <input>

加载与出错 .qc-loading

在内容将出现的位置放一条细进度线加一句具体说明，不另起全屏加载页。出错时同一位置改 role="alert"，写清原因，并在 .qc-loading__actions 里给恢复按钮。--page 铺满全局栏以下，--inline 用在卡片和列表尾部，--dark 用在 HUD 等深色表面。

<div class="qc-loading" role="status">正在读取旅途存档…</div>
<div class="qc-loading" role="alert">网络断开了，存档没有读到。
  <div class="qc-loading__actions"><button type="button">重新读取</button></div>
</div>

LXHUI.loading({ text: '正在读取…', inline: true });
LXHUI.loading({ error: true, text: '网络断开了', actions: [{ text: '重新读取', onClick: retry }] });

确认框 LXHUI.confirm

是/否对话框。打开后焦点落在「否」，防止误触；Tab 只在框内循环；Esc 或点遮罩等于「否」，关闭后焦点回到原来的按钮。onYes 返回 Promise 时，「是」进入提交中状态，完成后才关闭，失败则保持打开。破坏性操作加 danger: true。

LXHUI.confirm({
  title: '是否确定退出？',
  hint: '＊角色下次登录将出现在退出地点',   // 可信 HTML，可含 <br>
  icon: 'door',                            // ICONS 的 key
  yesText: '退出', noText: '再待会',
  danger: false,
  onYes: () => saveAndLeave(),             // 返回 Promise 时显示提交中
  onNo: () => {}
}).open();

主 HUD LXHUI.hud

平板式主界面：左上头像、等级和三条状态栏，右列功能钮，底栏三钮加聊天框，中央槽放地图等内容。功能钮都是带中文读屏名的真按钮（52 / 48px），选中态用 .is-on 或 aria-pressed，新消息用 .lxh-fbtn__dot。点下面的功能钮试试。

const hud = LXHUI.hud({
  night: false, lv: 42, avatar: url,
  status: [{ icon: 'radar' }, { icon: 'star', big: true, flash: true }],
  right: ['help', 'exit', 'wrench', 'scroll', 'shop', 'radar'],
  bottom: ['friend', 'star', 'map'],
  dots: ['scroll'],                      // 这些功能钮带新消息小点
  stage: '<div class="qc-loading qc-loading--dark">正在展开地图…</div>',
  onAction: (fn, btn) => open(fn)        // fn 为 ICONS 的 key
});

面板

角色属性面板 charpanel（御灵面板 + 五行生克星图）、胶片卡 filmcard（纯装饰，读屏跳过）、游戏内手机 phone、邮件图标 mail。五行节点上的字已改为墨色，原先乳白字压在乳白徽章上读不出来。

LXHUI.charpanel({
  name: '罗小黑', race: '猫妖', lv: 10,      // 纯文本，自动转义
  avatar: url, portrait: url,
  intro: '…',                               // 可信 HTML
  abilities: ['空间系<br>传送', '御灵系<br>金']
});
LXHUI.filmcard({ solid: true });  LXHUI.phone();  LXHUI.mail();

社交：名牌 · 聊天气泡 · 好友

名字、聊天内容都按纯文本插入，可以直接放玩家输入。好友面板里的搜索框是真输入框，输入就筛选；定位钮视觉 36px，触控区补到 44px。

LXHUI.nameplate({ id: 'ID 10086', name: '罗小黑', editing: true });
LXHUI.chatbubble({ avatar: url, text: playerMessage });
LXHUI.friends({
  rows: [{ name: '阿根', avatar: url }, { name: '小白' }],
  onLocate: (row, btn) => flyTo(row),
  onSearch: q => query(q)                  // 不传则在本地按名字筛选
});

数值：计数器 · 经验条 · 等级图 · 雷达

图形组件都带读屏文字：经验条是 role="progressbar"，计数器和雷达给出数值描述。数值超出 0–100 会被截断。

LXHUI.counter(20261020);
LXHUI.expbar(66, { label: '本级经验' });
LXHUI.lvchart([22, 34, 46, 60, 76]);
LXHUI.radar6({ values: [0.8, 0.5, 0.7, 0.4, 0.55, 0.6] });
LXHUI.radar5({ values: [0.9, 0.55, 0.75, 0.45, 0.85] });

选择：种族网格 · 谱系树 · 头像框

种族网格可以直接操作：类别钮和格子都是 aria-pressed 按钮，点击自动切换选中态，并回调 onTab / onSelect。头像框传 onEdit 时，角上的小钮变成真按钮。

LXHUI.racegrid({
  tab: 0, sel: 0, avatars: urls, names: ['黑猫', '狐', …],
  search: true,                             // 放真实搜索框
  onTab: i => {}, onSelect: (i, cell) => {}, onBack: () => {}
});
LXHUI.racetree();
LXHUI.avaframe({ gold: true, avatar: url, onEdit: () => pickAvatar() });

图标 LXHUI.ICONS

原始 SVG 字符串，众生之门的 LxhIcon、生态和经营模块直接取用，内容不变。放进按钮时请给按钮写读屏名（中文名表 LXHUI.LABELS），图标本身加 aria-hidden。点一下复制 key。

规则

类名是契约旧类名和 LXHUI 的旧参数全部保留。要改造型就新增修饰类（--danger），不要改已有选择器的含义。动选择器前先在 apps/ 里搜一遍消费者。
只用 token组件里不写色值，新颜色先加成 --lxh-* token 再用。实心色块上的字用 --lxh-on-fill，亮橙色块上用 --lxh-on-ochre。
五种状态每个可点控件都要有悬停、按下、键盘焦点（:focus-visible）、禁用和提交中（aria-busy）；输入框要有校验失败（aria-invalid）。
44px 与对比度可点区不小于 44px，视觉更小的钮用 ::before 扩大触控区。正文对比 ≥ 4.5:1；浅底焦点环用青玉，深底用描金（容器加 data-lxh-surface="dark"）。
文本转义name、text、id 自动转义，可以放玩家输入；title、hint、intro、abilities 接受可信 HTML，不要把用户输入放进去。
减少动态系统开启「减少动态效果」时，闪烁、光标、扫光和过渡都会停掉。新增动画同样放进 prefers-reduced-motion 分支。
