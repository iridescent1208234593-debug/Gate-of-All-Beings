添加到桌面

将众生之门安装到电脑或添加到手机主屏幕，无需应用商店下载。

先在浏览器中打开

在微信、QQ 等应用内，请打开右上角菜单，选择在浏览器中打开。iPhone 请使用 Safari；安卓请使用手机自带或其他支持添加桌面的浏览器，再选择对应教程。

用 Safari 添加

先用 Safari 打开本页或众生之门首页，再按下面三步操作。下图展示了“分享”和“添加到主屏幕”的位置；系统版本不同，菜单样式可能有所区别。

  1. 打开分享菜单

    如果浏览器菜单里出现下图所示的“分享”，点击它。也可以直接点击工具栏中方框向上箭头的分享图标。

  2. 选择“添加到主屏幕”

    在分享菜单中向下滚动，找到这个选项。

  3. 确认名称，点击“添加”

    名称填写“众生之门”。如有“作为网页 App 打开”选项，请保持开启。

前两步使用菜单截图，最后一步为确认页示意。实际界面随系统版本变化。查看 Apple 官方说明

用安卓浏览器添加

可先点击上方“点击下载桌面快捷打开方式”。浏览器支持一键安装时会弹出真实确认；未提供此能力时，请选择你正在使用的浏览器，查看手动方法。

手机自带浏览器

打开本页后，查看浏览器的菜单、工具箱、收藏或分享区域，寻找“添加到桌面”“添加至桌面”“发送到桌面”等选项。找到后确认名称并添加；如果没有该选项，当前版本可能未提供此功能。

华为浏览器

以下为华为官方操作截图，适用于 HarmonyOS 5.0 以下系统。图中以华为网站为例，操作时请先打开众生之门。

  1. 打开浏览器菜单

    在众生之门页面，点击浏览器底部右侧的菜单。

  2. 选择“添加至”

    在打开的浏览器菜单中，点击星形图标的“添加至”。

  3. 选择“桌面”，再确认

    添加位置选择“桌面”，核对网址为众生之门后点击“确定”。

图片来源：华为官方操作说明。HarmonyOS 5.0 及以上入口不同，请查看官方说明中的对应版本教程。

荣耀浏览器

在浏览器菜单、收藏或分享区域查找“添加到桌面”等选项。荣耀不同机型和版本的入口可能不同；未找到时，请查看该版本的浏览器帮助。

小米 / REDMI 浏览器

查看浏览器菜单或工具箱，寻找“添加到桌面”；也可检查收藏或书签的编辑选项是否提供桌面入口。位置随版本变化，没有该选项时请查看浏览器帮助。

OPPO / 一加 / realme 浏览器

打开浏览器菜单，检查工具、收藏或分享区域是否有“添加到桌面”等选项。不同品牌和版本不保证有同一入口；没有时请查看浏览器帮助。

vivo / iQOO 浏览器

检查浏览器菜单、收藏或历史记录中的网址操作，寻找“添加至桌面”等选项。具体入口请以当前系统和浏览器版本为准。

QQ 浏览器

查看菜单里的收藏或书签操作，以及网址的编辑选项，寻找“发送到桌面”或“添加到桌面”。这是浏览器自身的操作；没有相应入口时，网页无法替浏览器创建桌面图标。

UC 浏览器

查看菜单中的收藏、书签或网址操作，寻找“手机桌面”或“添加到桌面”等选项。不同版本可能没有同一入口，未找到时请查看浏览器帮助。

夸克

检查网页菜单、收藏或分享区域是否提供“添加到桌面”。若当前版本没有该功能，可复制网址到另一款支持添加桌面的浏览器。不能将添加到夸克首页当作已经添加到手机桌面。

百度 App 内网页

先在网页菜单中寻找“在浏览器打开”，转到手机浏览器后按对应教程操作。添加到 App 内收藏或首页，不等于生成手机桌面图标。

360 浏览器

查看浏览器菜单中的收藏、书签或网址操作，寻找“添加到桌面”“手机桌面”等选项。没有相应入口时，当前版本可能不支持，请查看浏览器帮助或使用其他已支持的浏览器。

下面三张图仅为 Chrome 界面示意，其他浏览器的菜单可能不同。

  1. 打开浏览器菜单

    用 Chrome 打开本页或众生之门首页，再打开浏览器菜单。

  2. 选择“添加到主屏幕”

Edge 安卓版

打开浏览器菜单，寻找“添加到手机”“添加到主屏幕”或安装相关选项；具体名称因版本而异。如果上方按钮能调起安装，直接按浏览器确认即可。

三星浏览器

检查浏览器菜单的“添加页面至”等选项，寻找主屏幕入口；具体名称和位置以当前版本为准。如果没有相应功能，可继续以网页方式访问。

Firefox 安卓版

打开网页后，展开浏览器菜单，选择“添加到主屏幕”，确认名称并完成添加。具体界面以当前版本为准。

Firefox 官方操作说明

各浏览器的功能和菜单会随版本变化。如果添加后没有桌面图标，可检查系统是否允许该浏览器创建桌面快捷方式。部分浏览器只创建网页快捷方式，点击后仍会显示浏览器界面；不保证都能变成独立窗口。

安装到电脑

  1. 使用 Chrome 或 Edge 打开

    浏览器允许安装时，点击上方“点击下载桌面快捷打开方式”，会弹出浏览器提供的真实安装确认。

  2. 没有弹出安装确认时

    检查地址栏右侧的安装图标，或在浏览器菜单中查找“安装应用”“将此站点安装为应用”等选项。不同版本的名称和位置可能不同。

  3. 确认安装

    按浏览器提示完成安装。Mac 用户也可以在支持的 Safari 版本中选择“文件 → 添加到程序坞”。

浏览器未提供安装入口时，仍可继续在网页中使用。安装后的独立窗口也需要联网。

添加后，请回到手机主屏幕查看图标。使用时仍需联网；进入其他子站时，可能会打开浏览器页面。
