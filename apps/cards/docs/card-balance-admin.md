# 卡牌数值后台与功能手册

更新：2026-10-24

本文说明众生之门「灵卡图鉴」中的数值编辑器、它保存的数据，以及本机后台的启动与恢复方式。数值配置与浏览器旅途存档分开保存。

## 打开图鉴

在运行中的本地卡牌页面进入 `#collection`。例如：

```text
http://127.0.0.1:5173/#collection
```

Cards 开发服务器默认端口为 5173。若你已启动其他本地入口（例如 5182），也可在该入口后使用 `#collection`。从线上或非本机地址打开时，图鉴为只读；管理功能只向本机同源连接开放。

页面会显示配置连接状态、版本号、已调整卡牌数量和编辑权限。点击卡牌打开编辑窗口；可搜索名称、效果或编号，也可按同行者筛选。

## 编辑和保存

编辑器提供即时预览。改动只留在当前草稿中，点「保存数值」后才写入后台；「取消修改」会放弃草稿。「恢复默认并保存」只删除当前卡的覆盖值，并在保存前自动备份上一版。

允许编辑的项目：

| 项目 | 可选范围与说明 |
| --- | --- |
| 灵力消耗 | 0–10 的整数；默认每回合恢复 3 点灵力。 |
| 作用目标 | 单个敌人或全部敌人；扩展敌方效果，自身增益仍只结算一次。 |
| 出牌条件 | 无额外条件、生命低于一半、手牌全为攻击牌。 |
| 使用后消耗 | 开启后本场战斗不再抽到，下场战斗恢复。 |
| 效果数值 | 18 种效果；每项只能填写其提示范围内的非负整数。设为 0 即关闭该项。 |

效果词典和精进加成会显示在编辑器各字段旁及「功能说明」中。编辑器调整的是卡牌基础配置；精进仍按原规则计算。轮回卡的自身目标和生命百分比专属条件不在此编辑范围内。

调整会影响这张卡在本页面后续的费用与结算，不会重算已经发生的伤害或已获得的状态。其他已打开的页面请点「重新加载配置」或刷新。图鉴中可见的卡不代表已经解锁、加入当前牌组或奖励池；数值调整也不会改变卡牌身份、同行者能力或解锁状态。生态个体卡的数值覆盖与已登记个体资料会一并保存在后台。

## 效果范围

所有效果均以编辑器实际显示的限制和帮助文字为准：

| 效果 | 上限 | 结算说明 |
| --- | ---: | --- |
| 伤害 | 999 | 加上力量后结算，并受目标格挡和易伤影响；精进 +3。 |
| 格挡 | 999 | 抵消敌方伤害；下个己方回合重置为领域提供的格挡；精进 +3。 |
| 抽牌 | 10 | 立即抽牌，手牌最多 10 张；精进 +1。 |
| 获得灵力 | 20 | 本回合立即增加可用灵力，下回合重置为 3；精进 +1。 |
| 力量 | 99 | 本场持续增加每次伤害结算值；精进 +1。 |
| 虚弱回合 | 99 | 敌方攻击伤害降低 25%，每次敌方行动后减少 1。 |
| 易伤回合 | 99 | 目标受到的攻击伤害增加 50%，敌方行动后减少 1。 |
| 侵蚀层数 | 999 | 敌方行动前扣除等于层数的生命，无视格挡，随后减少 1 层。 |
| 木灵 | 999 | 每次结束回合对首个存活敌人造成伤害；精进 +1。 |
| 领域守护 | 999 | 下个己方回合开始获得对应格挡，本场持续；精进 +1。 |
| 恢复生命 | 999 | 立即恢复生命，不超过生命上限；精进 +2。 |
| 回灵 | 99 | 存活进入下个回合时恢复相应生命，然后减少 1 层。 |
| 格挡转伤害 | 1 | 1 启用、0 关闭；额外造成等同出牌前格挡的伤害，不消耗格挡。 |
| 每层负面追加伤害 | 99 | 目标每层虚弱与易伤各追加此数值的伤害。 |
| 清除目标负面 | 1 | 1 启用、0 关闭；伤害结算后清除目标原有虚弱与易伤。 |
| 生命消耗 | 999 | 出牌时扣除生命；当前生命必须严格大于该数值。 |
| 降低敌方攻击 | 999 | 降低目标本场基础攻击，最低为 0。 |
| 半血额外抽牌 | 10 | 出牌前生命低于上限一半时，额外抽取指定牌数。 |

「全部敌人」只扩展敌方效果；抽牌、治疗、灵力和格挡等自身效果仍只结算一次。

## 本地启动

在 `E:\Projects\server\app\src\cards` 目录运行：

```powershell
npm run dev
```

Cards 的 Vite 插件会在开发服务中挂载数值 API，无需单独启动数据库或 API 进程。`npm run dev` 默认监听 5173；本机可用 `http://127.0.0.1:5173/#collection` 打开图鉴。

如果要检查构建后的页面，可运行：

```powershell
npm run build
npm run preview -- --host 127.0.0.1 --port 5178 --strictPort
```

预览地址为 `http://127.0.0.1:5178/#collection`。构建本身不会发布网站。统一门户的 Cards 模块挂载在 `/app/modules/cards/`；门户代理的数值 API 使用 5178 端口。若通过统一门户访问，按工作区根 README 的门户启动流程启动服务。

## 文件、版本和备份

- 当前配置：`apps/cards/data/card-balance/config.json`
- 自动备份：同目录的 `backups/`
- 浏览器旅途存档：保存在浏览器存储中，不在上述配置文件内。

数值配置文件由本地服务创建，属于运行数据且被 Git 忽略。首次保存会从代码默认值开始创建配置。每次保存或恢复默认都会递增 `revision`，并先将上一版写入 `backups/`，再原子替换当前配置。过期版本会收到冲突提示，避免两个页面互相覆盖；重新加载后再编辑即可。强制停止服务时若留下 `.write-lock` 目录，确认本工程开发和预览服务均已停止后再移除该锁目录。

恢复备份时，先停止本工程开发/预览服务并另存当前 `config.json`，再将选定的后台备份复制为 `config.json`，然后重启服务并重新加载页面。图鉴导出的完整 JSON 也可用于恢复。若文件格式损坏，后台会拒绝写入并保留原文件；请从备份恢复。后台备份不包含据点、生态库存或旅途进度。

## 接口与访问权限

| 方法与路径 | 用途 |
| --- | --- |
| `GET /api/card-balance` | 读取配置版本、覆盖值和可编辑状态。本机同源连接另获当前进程写入令牌及完整备份数据。 |
| `PUT /api/card-balance/cards/:id` | 保存或重置单卡。请求体为 `{ "revision": 1, "value": { ... }, "individual": { ... } }`；`value: null` 表示恢复默认。生态个体卡需要提供可校验的个体资料或后台已保存资料。 |

API 路径会随页面基路径挂载：Cards 开发入口使用 `/api/card-balance`；统一门户模块使用 `/app/modules/cards/api/card-balance`，由门户代理到本地数值服务。

写入要求请求来自本机回环连接，页面主机为 `127.0.0.1`、`localhost` 或 `::1`，来源与主机匹配，并携带当前服务进程颁发的令牌。服务重启后旧页面的令牌失效，刷新页面即可重新取得。非本机连接只读。未知字段、无效卡牌编号、超范围或非整数值、过期版本及不合法的生态个体资料都会被拒绝。静态托管没有后台时，页面会提示后台未启动并暂停历练操作，避免使用错误数值。
