### 3.3 数值面板组件 `ui/SixSystemPanel.js`

复用共享库既有能力（只调用、不修改）：

| 依赖 | 用途 |
|---|---|
| `LXHUI.radar6({labels, values})` | 六维雷达（六系数值） |
| `LXHUI.wuxingSVG({title, showStar})` | 五行星图 |
| `SixSystemIcons.create()` | 六系图标 |

API：`render(opts)` / `mount(selector, opts)` / `renderFromRecord(record)` / `fallbackRadar(labels, values)`。
`LXHUI.radar6` 缺失或抛错时自动降级为内置 SVG 雷达，保证面板独立可用。

```js
const el = SixSystemPanel.render({
  name: '罗小黑', subtitle: '妖灵会馆 · 无限的徒弟', tier: 'C 精锐',
  systems: ['jin', 'kongjian'],
  values: [88, 62, 70, 55, 60, 95],          // 金 木 水 火 土 空间
  stats: { hp: 6176, attack: 372, defense: 269 },
  source: 'character_stats.json · id=1'
});
document.querySelector('#card-slot').appendChild(el);

// 或直接从数值产物渲染
SixSystemPanel.mount('#card-slot', {
  name: '无限', systems: ['jin','kongjian'],
  values: [95, 60, 66, 58, 62, 92],
  stats: { hp: 8666, attack: 510, defense: 372 }
});
```
