# 01 · 数值模型

> 所属项目：六系演武（six-system-arena）
> 模型文件：[stat-model.json](../data/stat-model.json)　主数据源：`worldview_luoxiaohei_v4.db`（只读）

## 1. 定位

为数据库中的每一个角色生成一套**可复现、可解释、可人工纠偏**的战斗数值，供卡牌游戏、经营游戏、模拟游戏三个子系统共用。模型只做**推导**，绝不写回数据库。

## 2. 五要素

| 要素 | 取值 | 来源 |
|---|---|---|
| hp | ≥0 整数 | 境界基准 × 系别偏向 × 定位加成 × 能力加成 × 多系加成 × 扰动 |
| attack | ≥0 整数 | 同上 |
| defense | ≥0 整数 | 同上 |
| element | `jin` / `mu` / `shui` / `huo` / `tu` / `kongjian` / `none` | 能力表 + 能力摘要关键词推导 |
| realm | 练气 / 筑基 / 金丹 / 元婴 / 化神 / 渡劫（1–6 档） | `type` / `deity` / `category` 规则判定 |

多系角色额外输出 `systems`（有序去重，最多 3 个）与 `systems_label`；`element` 取首个匹配系，作为属性克制的主属性。

## 4. 数值公式

```
hp      = round(hpBase      × bias.hp  × type.hp  × ability × multi × jitter)
attack  = round(atkBase     × bias.atk × type.atk × ability × multi × jitter)
defense = round(defBase     × bias.def × type.def × ability × multi × jitter)
```

- **系别偏向 bias**：火系攻击最高（atk ×1.14）、土系防御最厚（def ×1.16、hp ×1.10）、金系偏攻（atk ×1.10）、木系偏血（hp ×1.06）、空间系均衡偏攻（atk ×1.08）。
- **定位加成 type**：登神 ×1.20/1.15/1.10；主线核心 ×1.18/1.12/1.10；重要角色 ×1.10/1.06/1.05；执行者/妖族 ×1.05/1.03/1.03；其余 ×1.00。
- **能力加成 ability**：`1 + min(能力条数 × 0.02, 0.12)`。
- **多系加成 multi**：`1 + min((系别数 - 1) × 0.04, 0.08)`。
- **扰动 jitter**：由 `md5(character_id)` 派生，范围 ±3%。**确定性**——同一角色每次生成结果完全一致，便于对账。

## 5. 战力与分档

```
power = round(hp × 0.35 + attack × 4 + defense × 3)
```

| 档 | 名称 | power 区间 | 稀有度 |
|---|---|---|---|
| F | 凡品 | < 1200 | R |
| E | 良品 | 1200 – 2400 | R |
| D | 优品 | 2400 – 3600 | SR |
| C | 精锐 | 3600 – 4600 | SR |
| B | 绝品 | 4600 – 5800 | SSR |
| A | 神话 | ≥ 5800 | UR |

阈值按 488 名角色的实际分布校准（首轮结果：F 344 / E 74 / D 51 / C 15 / B 3 / A 1）。**主线角色集中于 C~A 档，杂项角色落 F~E 档**，符合"主线优先"的设计意图。

稀有度目标分布：R 60% / SR 30% / SSR 9% / UR 1%。

## 7. 系别判定与置信度

判定优先级：**能力明细表（character_abilities）> 能力摘要关键词 > 宽松字面兜底**。

| 置信度 | 含义 |
|---|---|
| `high` | 命中能力明细或"御灵系·X"精确写法 |
| `medium` | 命中能力摘要关键词（如"冰""火焰""空间"） |
| `low` | 仅宽松字面兜底或未命中（多为无系普通人） |
| `manual` | 由人工校准表覆盖 |

特殊规则：文本含"六大系"直接判为六系全覆盖（老君）。

## 8. 人工校准（纠偏通道）

编辑 [manual-overrides.json](../data/manual-overrides.json)，按键为角色 id：

```json
{
  "23": { "systems": [], "element_name": "无系（生灵系 + 心灵系）", "realm_id": 5 }
}
```

可覆盖字段：`systems` / `element_name` / `realm_id` / `hp` / `attack` / `defense` / `name`。改后重跑脚本即生效，输出中该角色带 `overridden: true` 标记。

## 10. 可扩展点

- 新增境界档 → 只改 `realm.levels`，脚本不动。
- 新增系别 → 改 `six-systems.json` + `stat-model.json → element.keywords`。
- 平衡性调参 → 只改 `elementBias` / `typeBonus` / `tiers`，重跑即可复现。
- 版本留痕 → `meta.model_version`、`meta.systems_version` 随产物落盘，便于比对。
