## 3. 根因分析（三项派生缺陷）

| 编号 | 缺陷 | 影响 |
| --- | --- | --- |
| **FIX-1** | `abilities_summary` 常以顿号并列多系（如「御灵系·金、土」），而元素关键词只做**整串精确匹配**，并列系被整体漏匹配 | 部分角色少判系别；土系因常出现在并列串末位而更易漏 |
| **FIX-2** | 境界（realm）推导只看 `type` 前缀 / 字符串包含，**「长老 / 馆长 / 十五仙 / 斗帅宫冠军」等高位身份无识别规则** | 高位角色被压至「金丹」等低阶，`power` 随之低估 |
| **FIX-3** | 主属性 `primary` 取 `ABILITY_HINTS` 的**固定顺序首命中**，土系在提示序列中排末位 | 多系角色中土系被其他系抢先，土系主属性被系统性低估 |
