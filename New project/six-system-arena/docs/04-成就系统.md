# 04 · 成就系统

> 核心玩法定位：**收集类成就**——让玩家为了"集齐"而反复对战，而不是为了数值而肝。
> 情绪设计双轨：**胜利 = 小黑与比丢登场 + 正向反馈；失败 = 小黑表情包安慰，不惩罚。**

## 1. 设计原则

1. **失败不惩罚**：败局不扣资源、不掉收集进度，只给情绪安抚。
2. **收集优先于数值**：成就奖励以"图鉴位、立绘、称号"为主，数值加成为辅且不影响对战胜负判定。
3. **可验证**：每个成就的达成条件都基于战斗日志或 `character_stats` 的确定性字段，不做"随机掉率"型判定。
4. **忠于原作**：角色称谓、阵营、羁绊文案均取自世界观数据库，不自行发明设定。

## 2. 胜利结算（正向反馈）

胜利后按固定节奏播放一段约 3 秒的结算：

| 时序 | 表现 | 说明 |
|---|---|---|
| 0.0s | 战斗定格 + 六系图标高亮（胜方主属性） | 复用 `ui/SixSystemPanel.js` 的图标 |
| 0.5s | **比丢**从画面侧边跑入，绕场一周 | 比丢为原作角色（id 18），非原创形象 |
| 1.5s | **罗小黑**跃入中央，与比丢并排 | 主角登场，情绪高点 |
| 2.0s | 弹出正向反馈文案 + 新收集品入账动画 | 见下表 |

**正向反馈文案池**（按达成难度选取，避免重复）：

- 常规胜：「小黑比了个大拇指，比丢已经开心地转圈了。」
- 首次击败某角色：「第一次赢下『{角色名}』，小黑把这一战画进了自己的小本子。」
- 越档取胜：「越级挑战成功！比丢愣了三秒，然后跳得比谁都高。」
- 连胜（≥3）：「三连胜。小黑假装淡定，尾巴藏不住。」

> 所有形象必须使用**罗小黑战记官方图**（见 05-素材白名单.md），禁止 AI 生图。

## 3. 失败结算（情绪安抚）

| 时序 | 表现 |
|---|---|
| 0.0s | 战斗定格，画面转柔和 |
| 0.4s | 展示**小黑安慰表情包**（官方表情包素材，随机 1 张） |
| 1.2s | 提示文案 + 一键"再来一次"按钮 |

**安慰文案池**：

- 「小黑拍拍你的头：我们再想个办法。」
- 「比丢把好不容易藏起来的果子分了你一个。」
- 「输了也没关系，妖灵会馆从不记这一笔。」

失败结算**不做**：扣资源、掉进度、扣图鉴、限时惩罚。

## 4. 收集类成就目录（首轮设计）

### 4.1 角色收集

| 成就 | 条件 | 奖励 |
|---|---|---|
| 初见小妖 | 解锁 1 名角色图鉴 | 称号「路过」 |
| 会馆常客 | 解锁 30 名角色 | 比丢的立绘 |
| 一馆之人 | 解锁 100 名角色 | 称号「妖灵会馆·常驻」 |
| 全线通晓 | 解锁全部 488 名角色 | UR 收藏卡「众生之门」 |

### 4.2 六系收集

| 成就 | 条件 |
|---|---|
| 金木水火土 | 集齐金 / 木 / 水 / 火 / 土 五系各至少 1 名 C 档以上角色 |
| 空间入门 | 拥有 1 名空间系角色并使用其主属性取胜 1 次 |
| 六系通演 | 用六种主属性各取得 1 胜 |

### 4.3 战斗收集

| 成就 | 条件 |
|---|---|
| 主线纪录 | 击败全部 30 名主线角色各 1 次 |
| 越阶者 | 越档挑战取胜 5 次 |
| 镜中人 | 镜像战取胜 3 次 |
| 稳如老树 | 单场战斗零损血取胜 |

### 4.4 收集进度与稀有度挂钩

稀有度（`character_stats.rarity`）作为收集权重的展示维度：集齐 R 档 → 铜章；集齐 SR → 银章；集齐 SSR → 金章；集齐 UR → 神话章。

## 5. 数据落点

| 内容 | 落点 |
|---|---|
| 成就定义 | `data/achievements.json`（P1 产出） |
| 达成判定所需字段 | `data/generated/character_stats.json` 的 `tier` / `rarity` / `mainline` / `systems` |
| 战斗记录 | 由经营 / 模拟子系统写入的统一战斗日志（本子系统只定义字段契约） |

**字段契约**：`{ battle_id, mode, my_character_id, opponent_id, opponent_type, result, turn_used, hp_left, seed }`。
成就判定只需读这份日志 + 数值产物，无需数据库。

## 6. 与对战系统的联动

```
战斗结束 → 结算（胜/负） → 触发成就判定 → 更新收集图鉴 → 播放对应反馈动画
```

- 胜利：先播"小黑 + 比丢"登场（约 3s），**再**弹成就解锁（避免两条动画打架）。
- 失败：只播安慰表情包，**不**触发成就判定，也不显示进度条。
