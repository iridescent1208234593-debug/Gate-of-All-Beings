## 4. 裁切建议

| 用途 | 建议来源 | 裁切 |
|---|---|---|
| 卡牌主将图 | `images\<角色名>\` 首张 | 竖版 3:4，主体头部保留上 15% 留白 |

| 结算登场动画（小黑 / 比丢） | `images\罗小黑\`、`images\比丢\` | 保留全身，抠底透明 PNG 输出，禁止改画 |

| 活动 / 节日界面 | `罗小黑节气贺图（gallery素材）\` | 按原图比例，仅做整体缩放 |

**通用约束**：只允许**等比缩放**与**矩形裁切**，禁止重绘、加滤镜、改色、去水印；禁止二次创作。

## 5. 表情包采集与审查流程

失败结算需要"小黑安慰表情包"，该素材**本轮未采集**（白名单目录中尚未定位到官方表情包专项目录）。采集时**必须**逐项通过以下审查：

1. **来源可追溯**：仅接受官方渠道（官方微博 / 官方微信公众号 / 官方 B 站账号 / 官方发行的表情包专辑）。
2. **非 AI 生成**：确认非生成式图像；目录名或来源含 `ai-` 前缀的一律排除。
3. **非同人**：作者署名为官方或未署名的官方发布内容；同人作者作品一律排除。
4. **留存来源凭证**：每张图记录 `来源 URL + 抓取时间 + 判定依据`，写入素材台账。
5. **落地位置**：通过审查的图统一放入 `assets\` 下官方表情包目录后再引用，**不得**直接引用外链。

> 临时兜底：在官方表情包到位前，失败结算可复用 `images\罗小黑\` 的现有官方立绘（裁切为方形）作为安慰图，不得使用任何非官方图像。
