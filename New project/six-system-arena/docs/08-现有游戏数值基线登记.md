## 5. 基线性质声明（必须随引用一起展示）

1. **未精校**：站点三池卡牌（25 + 70 + 3）与 3 名英雄的数值均为 demo 版本，`cardBalance.ts` 只做了**合法性校验**（上限 / 类型 / 条件），未做平衡性调优；`README` 未声明任何平衡目标。
2. **未分六系**：站点**没有任何 0–100 的六系分值**；`school/element` 只是**归属标签**（有 / 无），不是强度。
3. **不作为权威对照**：本项目数值全部标记 `inferred` / 带 `source` 溯源；与站点 demo 数值**不存在权威对照关系**，不得表述为"官方数值"。
4. **互不写入**：站点数值文件本轮**只读**；本项目产物落在 `six-system-arena/` 内。
