## 4. 回滚操作

```powershell
cd "E:\Projects\New project\six-system-arena"

# 1) 还原共享 UI 库
python data\scripts\patch_lxh_icons.py --rollback

# 2) 重新生成数值（覆盖式，幂等）
python data\scripts\generate_stats.py --scope all

# 3) 校验产物一致性
python -c "import json;d=json.load(open(r'data/generated/character_stats.json',encoding='utf-8'));print(d['meta']['total'],d['meta']['tier_distribution'])"
```

`generate_stats.py` 使用 `md5(character_id)` 派生扰动，**同一输入必得同一输出**，因此"回滚 = 重跑"即可复现历史数值。
