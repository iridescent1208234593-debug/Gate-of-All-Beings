# 03 · 对战系统

> 目标：一套忠于《罗小黑战记》世界观、可直接挂到卡牌 / 经营 / 模拟三个子系统的战斗内核。
> 支持两种对手：**官方角色**（来自世界观的 488 名角色）与**自身镜像**。

## 1. 设计原则

1. **忠于世界观**：六系 = 金 / 木 / 水 / 火 / 土 / 空间；设定锚点为"御灵系"与"领域"。
2. **数据驱动**：双方数值全部来自 `data/generated/character_stats.json`，不硬编码任何角色。
3. **确定性可复现**：同一套输入（角色 + 卡组 + 随机种子）必然复现同一场战斗，便于回放与对账。
4. **主属性克制**：多系角色以 `systems[0]` 作为主属性参与克制，其余系别体现为技能多样性。

## 2. 战场参数

| 参数 | 值 | 说明 |
|---|---|---|
| 回合上限 | 30 | 超时判血量百分比高者胜 |
| 先手 | 速度快者；相同则 `attack` 高者 | 速度 = `defense × 0.5 + attack × 0.5`（简化模型） |
| 基础伤害 | `max(1, attack × 系数 - defense × 0.45)` | 系数由卡牌类型决定 |
| 暴击 | 10% 概率 ×1.5 | 由种子决定，不看运气面板 |
| 能量 | 每回合 +1，上限 10 | 用来释放技能卡 |

## 3. 六系克制环

```
金 → 木 → 土 → 水 → 火 → 金      （主循环，克制方伤害 ×1.25，被克方 ×0.85）
空间 ⇄ 全体                      （空间系不被克制，也不克制他人，但自身技能无视 20% 防御）
```

- `jin` 克 `mu`，`mu` 克 `tu`，`tu` 克 `shui`，`shui` 克 `huo`，`huo` 克 `jin`。
- `kongjian` 与任何系别均为 ×1.00，但技能可穿透 20% 防御。
- `none`（无系）不参与克制，系数恒为 ×1.00。
- 同系对战 ×1.00。

选用该闭环而非五行相克全序，是为了在六系棋盘上保持"每系恰好克制 1 系、被 1 系克制"，克制关系对称、易于平衡。

## 4. 卡组分配规则

卡组 = **1 张主将卡 + 4 张技能卡 + 1 张羁绊卡**，共 6 张。

| 卡位 | 生成规则 |
|---|---|
| 主将 | 角色本体，数值取 `character_stats` 的 hp / attack / defense |
| 技能 1–N | 按角色 `abilities` 依次生成，最多 4 张；不足 4 张时用该系通用技（如"御灵·X·斩"）补位 |
| 羁绊 | 按 `systems[0]` 取该系羁绊（如 `jin` → "御灵·金·锋锐：攻击 +8%"），或按所属阵营（妖灵会馆 / 龙游 / 会馆执行者）取阵营羁绊 |

**稀有度与卡组强度**：`character_stats.rarity`（R/SR/SSR/UR）决定技能卡数量上限——R 2 张、SR 3 张、SSR/UR 4 张。这条规则让"稀有度"真正影响手感，而非只影响数值。

**主线优先**：`mainline: true` 的角色（30 名）默认解锁完整卡组；非主线角色初始只开放 2 张技能卡，需通过经营 / 收集玩法解锁。

### 4.1 技能卡构成与去重（R5）

技能卡按三个来源分层生成，来源写入 `source_kind` 字段，便于审计与后续替换：

| `source_kind` | 含义 | 生成条件 |
|---|---|---|
| `character_ability` | 角色真实能力（源自 `character_abilities` 明细） | 该角色有可用能力明细时优先使用 |
| `primary_fallback` | 主系通用技（如"御灵·金·锋锐斩"） | 能力明细不足、需补足主系占比时 |
| `generic_fallback` | 六系中立通用技（如"灵质·冲击"） | 前两者用尽后按槽位补位 |

- **保序去重**：同一套卡组内技能名按能力顺序去重，**同名只保留首个**（`rules.skill_card_dedup`）；补位阶段从每系技能池取未用名，池耗尽时追加 `·改N` 后缀，确保任何卡组不出现组内同名技能。
- **标签**：每张技能卡带 `tags`（输出 / 控制 / 续航 / 爆发 / 穿甲 / 通用 / 灵活 等），为后续"卡组流派"扩展预留字段，不影响现有数值。

### 4.2 获得节奏分层（非数值稀有度校准 · R5）

**问题**：`stat-model.json` 的稀有度由战力分档映射决定，世界里存在大量低战力同人 / 动物条目，导致实得 R 档占 85.7%（目标 60%）。**本轮不改任何数值字段**（hp / attack / defense / power / tier / rarity 逐条零漂移），改用**获得节奏分层**在非数值层收敛玩家侧稀缺度。

| 节奏层 | 名称 | 目标占比 | 实得角色数 | 含稀有度构成 | 前置里程碑 | 投放定位 |
|---|---|---|---|---|---|---|
| P4 | 传说节奏 | 1% | 5 | UR×1 / SSR×3 / SR×1 | 3 | 终局投放（战力序列头部） |
| P3 | 史诗节奏 | 9% | 44 | SR×44 | 2 | 中期投放 |
| P2 | 稀有节奏 | 30% | 146 | SR×21 / R×125 | 1 | 早期投放 |
| P1 | 常见节奏 | 60% | 293 | R×293 | 0 | 初始投放 |

- **分层规则**：按 `power` 降序（同战力按 `id` 升序）排名切分 P4/P3/P2/P1，`rules.acquisition_pacing` 固化 `shares` / `sizes` / `cuts` / `meta` / `rarity_pace_allowed` / `milestone_effect`。
- **达成判据**：投放节奏须随稀有度单调后移（`R ≤ SR ≤ SSR ≤ UR`），即 R 档只允许落在 P1/P2、UR 只允许落在 P4；违规 0 例由 `validate_achievements.py` 硬校验。
- **未达里程碑**者沿用"非主线初始只开放 2 张技能卡"兜底。
- **数值层不变**：本校准不修改 `stat-model.json`、`character_stats.json` 与任何 hp / atk / def 值，仅改动卡组产物的 `pacing` 字段与规则表。

## 5. 对战模式

### 5.1 与官方角色对战

- 对手从 488 名角色中按档位（tier）分组抽取，保证"打得到、打得过、打得爽"。
- 模式：**剧情战**（固定对手，主线推进）、**演武场**（随机同档对手）、**挑战赛**（越档挑战，胜率越低奖励越高）。

### 5.2 与自身对战（镜像战）

- 对手为自身卡组的精确副本，用于验证卡组强度与操作水平。
- 镜像战规则差异：双方同系 → 无克制加成；能量上限提升到 12；回合上限缩至 20。
- 结算特殊：镜像战胜负不计入"角色胜利收藏"，但计入"操作评价"。

## 6. 结算与联动

| 结果 | 动作 |
|---|---|
| 胜 | 播放**罗小黑 + 比丢**登场动画 → 正向反馈（详见 04-成就系统.md） |
| 负 | 展示**小黑安慰表情包** → 给予非惩罚性提示（"再来一次吧"），不掉资源 |

战斗产物（对局记录、胜率、卡组表现）写入经营 / 模拟子系统读取的**同一份战斗日志**，不在本子系统内落盘。

## 7. 与数值模型的关系

| 数值字段 | 战斗中角色 |
|---|---|
| `hp` | 主将血量条 |
| `attack` | 技能基础伤害来源 |
| `defense` | 减伤来源 |
| `element` / `systems` | 克制系数、羁绊归属 |
| `realm_name` | 显示用（练气~渡劫），并作为越档挑战的判定依据 |
| `tier` / `rarity` | 对手抽选、技能卡上限、奖励倍率 |

数值调平**只改 `stat-model.json` 并重跑脚本**，战斗规则无需改动——这是本次分层的核心收益。
