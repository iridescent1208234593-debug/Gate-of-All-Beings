## 对照香港节点，接入前还缺的信息

香港节点在仓库内对应：批准子域名 + Tunnel 记录 + 回环上游服务端口。新节点照此登记前，需要补齐：

1. **对外域名**：分配一个现有批准根域（`iridescently.xyz` / `.cn` / `.dpdns.org`）下的子域名；主机清单与入口策略不接受裸 IP。
2. **隧道**：Cloudflare Tunnel（或负责人批准的边缘方案）记录与 tunnel_id。
3. **服务端口**：该节点上实际运行的游戏 / web 服务监听端口，以及回环上游 URL（形如 `http://127.0.0.1:<port>`）。
4. **节点标识**：在 `infra/ingress/build_host_inventory.py` 的 `nodes` 映射中登记新节点名（现有仅 `hk`、`pc`）。
5. **分流方式**：目前仓库没有按负载 / 人数选节点的分发逻辑（见 `docs/networking.md` 预留接口，尚未实现）；需要明确是前置网关多上游，还是入口按节点选择。
